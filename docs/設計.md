# tick_clone 設計書

作成: 2026-10-06

## 基本方針

- **Markdownが正本**。1メモ = 1ファイル。アプリが無くなってもメモは残る
- **SQLiteは索引だけ**。消えても Markdown から作り直せる（このルールは崩さない）
- **軽く**。常駐DBサーバーなし、画面はビルド不要の素のJavaScript
- AI（Gemini）は「便利機能」。無くても基本機能は全部動く

## 置き場所

| もの | 場所 | 理由 |
|---|---|---|
| プログラム | リポジトリのフォルダ（`app/` `tools/` `extension/`） | 細かいファイルが多いので、クラウド同期のフォルダの外に置くのがおすすめ |
| メモのデータ | `data/notes/`（環境変数 `TICK_DATA` で変更可。それ自体が git 管理） | 改版履歴を git で取る。**リポジトリには含めない** |

## 全体の形

```
[Windowsのブラウザ]  [Androidのブラウザ(PWA)]
        │  オフライン時は端末内(IndexedDB)に保存し、つながったら同期
        ▼
  Tailscale（自分の端末同士だけの専用回線）
        ▼
[自宅PC] Python(FastAPI) ── notes/*.md（正本・git）
                         └─ index.db（SQLite・索引）
```

## メモファイルの形

`data/notes/2026/10/<id>.md`

```markdown
---
id: 01JABC...
created: 2026-10-06T20:15:00+09:00
updated: 2026-10-06T20:32:00+09:00
---
OPPOのROMについて調べる #Android #調べもの
明日までに田中さんに返事
```

- タイトル欄は持たず、**1行目をタイトル**として扱う
- タグは本文中の `#〇〇` から自動で読み取る（frontmatterには書かない＝二重管理しない）
- 改版履歴：保存のたびにgitへ自動コミット（連打しても数秒まとめてから1回）

## 機能と段階

### 第1段階（最初の版）
- メモの作成・編集・自動保存・削除（削除はゴミ箱フォルダへ移すだけ）
- `#` を打つと過去のタグ候補がポップアップ（IME変換中は邪魔しない）
- 全文検索、タグで絞り込み
- キーボード操作：`Ctrl+K` コマンドパレット、`Ctrl+N` 新規、`/` 検索 など
- gitによる改版履歴＋履歴の閲覧

### 第2段階
- 本文の「日時っぽい文字」の抽出（明日／10/8／来週火曜／15時 など）→ 書いた日を基準に日付へ直して索引化
- カレンダービュー・リストビュー
- PWA化（Androidのホーム画面から起動）＋オフライン編集と同期
- 同期の競合は「後勝ち＋負けた方を別メモとして残す」から始める

### 第3段階
- **自然言語ビュー**：「今日締切のものをリストで」→ Geminiが条件（JSON）に変換 →
  その**変換済み条件**をボタンとして保存。押すたびにAIは呼ばない。「今日」は押した日で計算
- AIによる日時抽出の補強

### TickTick に寄せる（2026-10-11 決定）
TickTick の使い心地を参考に、「リスト」「ノートとタスクの区別」などを引き継ぐ。
- **リスト**: frontmatter `list: 名前`（1メモ1つだけ。タグと違い複数は付けない）。`list: フォルダ/リスト` の2階層まで。空 = 受信箱。
  - 取り込み済みの本文末尾 `#リスト/…` は `list:` に移し、本文のタグ行から外す（`tools/migrate_lists.py`。試運転→確認→適用）。
  - 左ペインに「リスト」欄（受信箱・フォルダ・リスト、件数、ドラッグで移動、右クリックで名前変更）。メモのメニューにも「リスト」。
- **ノートとタスク**（実装済み・画面の版 v26）: メモ単位で `kind: note | task` を持つ。`kind:` が無い古いメモは、`status:` か期日があればタスク、無ければノートとして読む（TickTick の取り込み結果と同じ。ノートは約530件）。
  - ノートは完了できず（○ではなく 📝）、「期限切れ」に出ない。ノートに期日を付けるとタスクになる。完了・期日の変更で種類が勝手に変わらないよう、古いメモは変更前に `kind:` を書き留める。
  - 新規メモは、`n` = タスク / `Shift+N` = ノート。リストごとの「新しいメモの種類」は `data/settings.json` の `listKinds` に保存（無ければタスク）。
  - 注意（実装）: 端末の送信待ち（outbox）の `op.kind` は create/put/delete の種別。メモの種類は `op.nk`（名前が衝突すると、delete として送られてしまうため）。
- リストの並び順と、空のリスト（メモが無くても残る）は、`data/settings.json` の `lists`（名前の配列）に保存する（タグの色と同じ設定ファイル。全端末で共通、gitに履歴）。設定に無いリストは、名前順で後ろに付く。

### フィルター（2026-10-13 実装・画面の版 v36）
- 保存した絞り込み。`data/settings.json` の `filters`: `[{id, name, match: "all"|"any", conds: [{t, v, not}]}]`（全端末で共通）。条件の種類 t: list / tag / priority / kind / status / due / event / title / text / pinned / completed / created / updated。
- 判定は端末側（`static/data.js` の `filterMatch`）。サーバーは、設定の保存時に、形を整えるだけ（`main.py` の `_clean_filters`）。
- 状態の条件（status / completed）が無いフィルターは、完了したメモを除く（ふだんの一覧と同じ）。
- **自然言語ビュー（第3段階）の土台**: 自然言語 → この条件のJSON、に変換して保存すれば、同じ画面・同じ判定で動く。

### 中止（キャンセル）（2026-10-15 実装・画面の版 v37）
- `status: abandoned`（TickTick の「Won't Do」と同じ。取り込み時から、データにはあった）を、画面から選べるようにした。中止日は `cancelled:`。
- **実績には数えない**: 完了日（`completed:`）を付けず、完了日の一覧・カレンダー・条件・行動記録への受け渡しの対象は「完了」だけ。日付（期日）は残す。
- 繰り返す予定は「この回を中止（スキップ）」＝期日が次の回へ進む（`last_cancelled:`。完了日は付かない）。
- サーバー側: 完了・中止は、期日・繰り返しなどを反映したあとで行う（端末で、期日と繰り返しを決めてから、すぐ完了・中止した分が、1回の送信にまとまっても、次の回へ進む）。

### 自動でリストへ入れる仕組み（2026-10-19 実装・画面の版 v39〜v40）
- **リストの設定**（`data/settings.json`）
  - `listRoutes`: `deadline` / `event` / `note` → 入れ先のリスト（締切にした・予定にした・ノートにしたメモ。リスト未設定のメモだけ）。
  - `listPromote`: 元のリスト → `{to, days}`（期日つきの未完了タスクの締切が、`days` 日以内になったら、`to` へ移す）。
- `listToNote`: リスト名の配列。そのリストへ入れたメモは、**期日の無い未完了のタスクに限り**、ノートにする（`app.js` の `enterList` が、リストへ入れる全経路の入口）。
- **フィルターのルール**: 保存したフィルターの `to`（当てはまるメモを自動で入れるリスト）。リスト未設定のメモだけが対象で、フィルターの並び順が優先順位。
- **動くとき**: 操作の瞬間（種類・日付・タグ・本文の保存）、サーバー側の作成時（`note`。Chrome 拡張・共有）、アプリを開いたとき・日をまたいで戻ったとき（1日1回: 締切が近づいたタスクの移動と、フィルターのルールの一括適用。「元に戻す」つき）。
- 手でリストを決めたメモは、動かさない。まとめての日付操作・ドラッグ・「今日」「明日」では、動かさない（仕分けではないため）。

### いつかやる
- PDF・JPGの貼り付け
- バックアップ先（クラウド・非公開リポジトリ等。いまは `tools/backup.py --dest`）
- 自宅PC以外のサーバーへの引っ越し

## 技術

- サーバー：Python 3.10 + FastAPI + SQLite（FTS5で全文検索）
- 画面：HTML + 素のJavaScript（ES modules）、ビルド工程なし
- 履歴：git（コマンドを裏で呼ぶ）
- 外からの接続：Tailscale
