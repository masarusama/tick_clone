# tick_clone 使い方（ヘルプ・機能一覧）

最終更新: 2026-10-15（画面の版 v44）
（この文書を直したら、`python tools/build_help.py` でアプリ内のヘルプも更新する）
このページと同じ内容が、アプリの中でも読めます（キーボードの `?`、左メニューの「❓ 使い方」、`Ctrl+K` →「使い方」）。

---

## 1. これは何か
- メモ・タスクアプリ（TickTick のような使い心地を目指した、自分の PC で動かす自作アプリ）。メモ1件 = Markdown ファイル1つ。
- 検索や一覧を速くするための「索引」（SQLite）は、メモのファイルからいつでも作り直せます。**正本はメモのファイル**です。
- 自分の PC で動くサーバーに、PC・スマホ・Mac のブラウザからつなぎます（Tailscale などの、自分の端末だけの回線の中。インターネットには公開しません）。
- 一度開けば、**オフラインでも使えます**。変更は端末に先に保存され、つながったときに自動で同期されます。

## 2. 開く場所・使い始め
| 端末 | 開き方 |
|---|---|
| この PC | http://localhost:8765/ |
| スマホ・Mac など（Tailscale に入れた端末） | `https://<PC名>.<tailnet名>.ts.net/`（`tailscale serve` で出したアドレス） |

- スマホは、Chrome のメニュー →「ホーム画面に追加」で、アプリのように使えます。
- PC の電源が入っていて、サーバーが動いているときだけ、新しい内容が同期されます（サーバーは PC の起動時に自動で立ち上がります）。

## 3. 画面の見方
- **左**: メニュー（すべて・今日・次の7日間・期限切れ・日付なし・ノート・カレンダー・月カレンダー（大）・完了・ゴミ箱）と、リストの一覧、**フィルター**の一覧、タグの一覧。
- **中**: メモの一覧（上に検索欄・並び順）。
- **右**: 開いているメモ。上のバーに、期日・⏰・🔔・📎・整形表示/編集・履歴・⋯・＋新規。
- PC では、一覧の上の「＋ 新しいメモ」ボタンで新規メモを作れます。
- スマホは、一覧とメモが別画面です。左上の ☰ でメニュー、右下の ＋ で新規メモ、「‹ 一覧」で戻ります。
- **スマホの「戻る」ボタン（Android）**: アプリの外へ出ずに、いまの画面を**1つ閉じます**。順番は、拡大画像 → メニュー・ダイアログ（使い方・履歴・通知など）→ 選択モード → ☰ メニュー → 開いているメモ（→ 一覧へ）→ 絞り込み・検索・別の画面（→「すべて」へ）です。何も閉じるものが無い（「すべて」の一覧にいる）ときに押すと、アプリが閉じます。PC のブラウザの「戻る」は、いままでどおりです。

## 4. メモを書く
- **整形表示のまま書けます**。文字をクリックすると、その行だけが入力欄になります。
  - `Enter`: 次の行へ（箇条書き・チェックボックス・番号は続けて作る。空の項目で Enter なら終わる）
  - `Backspace`（行頭）: 前の行とつなぐ（記号つきの行は、まず記号だけ外れる）
  - `↑` `↓`（行頭・行末）: 隣の行へ
  - `Esc`: 入力を抜ける
- **全文をソース（文字だけ）で編集**したいときは、`Alt+P` か `e`。もう一度押すと整形表示に戻ります。
- 書き方（Markdown）: `# 見出し` / `- 箇条書き` / `- [ ] チェックボックス` / `1. 番号` / `> 引用` / バッククォート3つで囲むとコードブロック / `[題名](URL)` リンク
- **コピー・切り取り・貼り付け**（`Ctrl+C` `Ctrl+X` `Ctrl+V`。Mac は `Cmd`）:
  - 行を入力しているとき（行をクリックした状態）、またはソース編集のときは、ふつうのテキスト欄と同じです。右クリックのメニューも使えます。
  - 整形表示のまま、**行をまたいで文字を選ぶ**（ドラッグ）と、`Ctrl+C` で、記号つきの元の Markdown の行（`- [ ]` なども含む）がコピーされます。`Ctrl+X` なら、選んだ行を丸ごと切り取ります。
  - `Ctrl+A` は、整形表示の本文を全部選びます（そのまま `Ctrl+C` で、メモ全体をコピー）。
  - 整形表示のまま `Ctrl+V` すると、貼り付けた文が行として、選んでいる行の次（選んでいなければ末尾）に入ります。画像は、添付になります。
  - 1行の中の一部だけを選んだときは、見た目の文字がコピーされます。切り取りたいときは、その行をクリックして入力に入ってから `Ctrl+X`。
- ☐ ☑ は、クリックで切り替えます。
- 末尾の余白をクリックすると、書き足せます。
- **保存は自動**です（打つのをやめて約1秒後）。`Ctrl+S` で今すぐ保存。
- **URL を貼る**と、数秒後にページのタイトルつきのリンクになります。文字を選んでから URL を貼ると、その文字がリンクの題名になります。メモの右クリック →「リンクにタイトルを付ける」で、メモ中の URL をまとめて変換します。
- **画像・PDF**: メモの上にドロップ / `Ctrl+V` / 📎 ボタン。本文に表示され、下にも並びます。

## 5. リスト（TickTick と同じ「箱」）
- メモは、**1つのリスト**に入れられます（タグと違い、複数には入れません）。リストに入れていないメモは「📥 受信箱」です。
- 左のメニューの「リスト」欄に、受信箱・リストが並び、件数が出ます。押すと、そのリストのメモだけが一覧に出ます（もう一度押すと戻る）。
- 「フォルダ/リスト」の形（例: `仕事/営業`）で、フォルダにまとめられます（2階層まで）。フォルダを押すと、中のリストをまとめて表示します。▾ で開閉します。
- 入れ方: メモを左の**リストへドラッグ**（受信箱へ落とすとリストが外れます）/ メモのメニュー →「リスト」/ 上の「＋」で新しいリストを作って、開いているメモを入れる。
- 上の「＋」で、**空のリスト**を作れます（`仕事/営業` のようにフォルダ付きの名前も可）。メモは、あとからドラッグ / メニューで入れます。
- **並び順は、自分で決められます**。リストの行を**ドラッグ**して、好きな位置へ（行の上半分に落とすとその上、下半分ならその下。フォルダは、中のリストごと動きます。フォルダの中のリストは、同じフォルダの中でだけ動きます）。スマホなど、ドラッグできない端末は、リストを右クリック（長押し）→「先頭へ」「1つ上へ」「1つ下へ」。並び順は全端末で共通です。決めていないリストは、名前順で後ろに付きます。
- **締切・予定にしたとき、自動でリストに入れる**（任意の設定）: リストを右クリック →「締切にしたメモを、自動で入れる」「予定にしたメモを、自動で入れる」。たとえば、締切（〜まで）は Oneday、予定（〜に）は「具体的な次にとるべき行動」にしておくと、💡の「期日にする」「予定にする」を押したときや、メモのメニューで「予定にする」「締切に戻す」を選んだとき、**日付ピッカーで日付を選んだとき**（上のバーの📅の日付欄、メニュー →「期日」→「日付を選ぶ…」）に、そのリストへ入ります。日付ピッカーでは、予定の印が付いているメモは「予定」の、付いていなければ「締切」の入れ先になります。
  - **リストが未設定（受信箱）のメモだけ**が対象です。手でリストを決めたメモは動きません。「締切に戻す」で、リストを入れ直すこともしません。
  - 「今日」「明日」などの項目や、ドラッグで日付を入れたときは、自動では入りません（その日に動かすだけで、仕分けではないため）。もう一度同じ項目を選ぶと、設定が外れます。
- **ノートにしたとき、自動でリストに入れる**: リストを右クリック →「**ノートにしたメモを、自動で入れる**」。たとえば「資料そもそも行動できないよ」に設定すると、**ノートにした瞬間に、そのリストへ入ります**。
  - 働くとき: メニューの「種類」でノートにしたとき（まとめて操作でも）/ `Shift+N` で新しくノートを書いたとき / Chrome 拡張やスマホの共有で入れたメモ（共有されたものは、ノートとして入ります）。
  - ここでも、**リストが未設定のメモだけ**が対象です。手でリストを決めたメモや、リストを選んでから書いたメモは動きません。
- **このリストに入れたメモは、自動でノートにする**（逆向きの自動）: リストを右クリック →「このリストに入れたメモは、自動でノートにする」。たとえば「資料そもそも行動できないよ」に設定すると、**そのリストへ入れた瞬間に、メモがノートになります**（ドラッグ・メニュー・まとめて操作・自動振り分けのどれでも）。そのリストを開いて `n` で新しく書いたメモも、ノートです。
  - 対象は、**期日の無い未完了のタスクだけ**です。期日つきのタスク（予定の印つきを含む）や、完了済みのものは、タスクのまま入ります（勝手に締切を外さないため）。
  - 設定したとき、いまそのリストにある、対象のタスクにも当てはめるか聞きます（「元に戻す」で戻せます）。もう一度同じ項目を選ぶと、設定が外れます。
- **締切が近づいたら、別のリストへ移す**: リストを右クリック →「締切が近づいたら、別のリストへ移す」→ 移し先を選び、「締切が 3 / 7 / 14 / 30 日以内になったら」を選びます（目安は 7 日）。たとえば、Oneday から「具体的な次にとるべき行動」へ。
  - **アプリを開いたとき、1日に1回**、そのリストの中の、**期日が付いた未完了のタスク**で、締切が決めた日数以内（期限切れも含む）のものを、移し先へ移します。ノート・完了したもの・期日の無いものは、動きません。
  - 移したあとは、「3件: 締切が7日以内になったので…移しました [元に戻す]」が出ます。
  - 日付ピッカーなどで、すでに近い締切を付けたときは、「締切を自動で入れる」リスト（Oneday）ではなく、**最初から移し先**へ入ります。
  - 「移すのをやめる」で、設定を外せます。
- リストを右クリック →「名前を変える…」で、そのリストのメモ全部の名前が変わります。「リストを削除…」で、リストを消せます（中のメモは消えず、受信箱に戻ります）。
- 一覧で、リストを選んでいないときは、メモの行にリスト名（📋）が出ます。リストを選んでから新規メモを作ると、そのリストに入ります。
- TickTick から取り込んだメモは、元のリスト（Inbox・Someday など）に入っています。

## 6. タスクとノート（TickTick と同じ区別）
- メモには **種類** があります。**タスク**（○で完了できる。期日・繰り返し・通知が使える）と、**ノート**（読み物・資料。○は付けず、📝 の印が出る）です。
- 一覧では、タスクは○、ノートは 📝 が左に付きます。ノートは、完了にできません（`x` を押しても、案内が出るだけ）。「期限切れ」にも出ません。
- 左のメニューの「📝 ノート」で、ノートだけを一覧にできます。
- 切り替え: メモのメニュー →「種類」→ タスク / ノート。ノートに**期日を付けると、タスクになります**（期日はタスクのものなので）。
- **ノートは、日付（期日・予定・繰り返し）を持ちません。** ノートに期日を付けると、タスクになります。期日つきのメモを「ノートにする」と、確かめてから日付を外します（「元に戻す」で戻せます）。本文に書いただけの日付は、そのままカレンダーに出ます。
- 新規メモ: `n`（または「＋ 新しいメモ」）の種類は、場所で決まります。**リストを選んでいない「すべて」・受信箱・ノート・日付なしなどでは、ノート**（書くときは仕分けしない。日付を付けると、タスクになります）。リストを選んでいるときは、そのリストの設定（なければタスク）。日付を扱う画面（今日・次の7日間・期限切れ・カレンダー）では、タスク。`Shift+N` = いつでもノート、`Alt+T` = いつでもタスク。「今日」の一覧で作ると今日の期日、カレンダーで日を選んでいるときはその日の期日が付きます。
- リストを右クリック →「新しいメモの種類: ノート」にすると、そのリストで `n` を押したときも、ノートが作られます（読書メモ用のリストなど。TickTick の「ノート用のリスト」と同じ使い方です）。
- 取り込んだメモは、TickTick の区別のままです（タスクは○あり、ノートは📝）。

## 7. フィルター（保存した絞り込み）
- 条件を組み合わせた絞り込みに名前を付けて保存し、左のメニューの「フィルター」欄から、1回押すだけで開けます（件数も出ます）。TickTick の「フィルター」と同じ使い方です。
- **作る**: 「フィルター」の右の「＋」 → 名前を付けて、条件を足します。「いまの条件に当てはまるメモ: N 件」が、その場で出ます。
- **条件の種類**: リスト（受信箱も）/ タグ（親タグは子も含む）/ 優先度 / 種類（タスク・ノート）/ 状態（未完了・完了）/ 期日（今日・明日・7日以内・期限切れ・なし・あり）/ 予定・締切 / 題名に含む文字 / 本文に含む文字（空白で区切るとすべて含む）/ ピン留め / 完了した・作成した・更新した（○日以内）。
- **組み合わせ**: 「すべて満たす（かつ）」か「どれかを満たす（または）」。各条件は「含む」か「除く」を選べます（例: 題名に「日記」を含む、かつ、完了を除く）。
- **直す・並べる**: フィルターを右クリック（スマホは長押し）→ 編集 / 複製 / **当てはまるメモを、自動でリストへ入れる** / 1つ上へ・1つ下へ / 削除。フィルターは、全端末で共通です。
- **フィルターのルール（当てはまるメモを、自動でリストへ入れる）**: たとえば「`#日記` を含む」フィルターに「資料そもそも行動できないよ」を設定すると、**リスト未設定のメモが、その条件に当てはまった瞬間**（本文にタグを書いて保存したとき、タグを付けたとき、ノートにしたときなど）に、そのリストへ入ります。ほかに、**アプリを開いたとき（1日1回）**にも、リスト未設定のメモをまとめて当てはめます（Chrome 拡張などで入ったメモも、ここで入ります）。
  - 設定したとき、いま受信箱にある当てはまるメモにも、当てはめるか聞きます（「元に戻す」で戻せます）。
  - **リスト未設定のメモだけ**が対象です。手でリストを決めたメモは動きません。「締切・予定・ノート」の自動振り分けが先で、当てはまらなかったときに、フィルターのルールが働きます。複数のフィルターに当てはまるときは、**一覧で上にあるフィルター**が優先です。
- 状態（完了・未完了）や「完了した（○日以内）」の条件が無いフィルターでは、ふだんの一覧と同じく、完了したメモは除きます（「完了・中止も一覧に出す」で、含められます）。フィルターの編集画面の「**完了・中止したメモも含める**」にチェックを入れると、そのフィルターは、完了したメモも含めて出します（日記のように、完了にしたものも見たいとき）。
- 選んだフィルターの中でも、並び順・検索・複数選択・ドラッグは、これまでどおり使えます。

## 8. タグ
- 本文に `#仕事` と書くとタグになります。`#` を打つと候補が出ます（`↑↓` と `Tab`/`Enter` で確定）。
- `#本/小説` のようにスラッシュで区切ると、親子のタグ（親の `#本` を選ぶと、子のメモも出ます）。
- 左のタグを**右クリック → 色**を選ぶと、一覧のタグも帯も同じ色になります（色は全端末で共通）。
- 一覧のメモを、**左のタグへドラッグ**すると、そのタグが付きます。
- `g`: 一覧を、タグごとのグループ表示にする／やめる。

## 9. 期日・時刻・予定・締切
### 期日を付ける
- 上のバーの 📅 の日付欄と、時刻欄（空 = 終日）。`Alt+D` で日付欄へ。
- メモのメニュー（右クリック）→「期日」: 今日・明日・来週の月曜・1週間後・日付を選ぶ…・期日を消す。「時刻」: 9・12・15・18・21 時など。
- 本文に `!10/8` や `!明日` と書いても、期日になります（! の直後だけを読みます）。
- 一覧のメモを、カレンダーの日・「今日」「日付なし」などへ**ドラッグ**しても、期日が変わります。ドラッグ中は画面の下に「今日 / 明日 / 来週の月曜 / 日付なし / 完了 / ゴミ箱」の落とし先が出ます。

### 締切と予定
- 期日は、ふつうは**締切**です。過ぎると「期限切れ」に出ます。
- **予定**にすると、過ぎても期限切れになりません（会議・ランチ・通院など）。メモのメニュー →「予定にする」。「🗓」の印が付きます。
- 予定には、**終わりの時刻**（17:00-19:00）や、**複数日**（10/12〜10/14）を持たせられます。
- **予定・タスクを中止（キャンセル）にする**: メモのメニュー →「**中止にする（キャンセル）**」。やらないことになった予定・タスクに使います。
  - メモは残り、「完了・中止」の一覧に移ります（取り消し線と ×、「🚫中止 26/10/15」と出ます）。**日付（いつの予定だったか）はそのまま残ります。**
  - **実績（完了）には数えません。** 完了日が付かないので、カレンダーの「完了日」、「完了した（○日以内）」の条件、並び順「完了日」には出ません。完了・中止の両方を含むのは、「完了・中止」の一覧と、フィルターの状態「完了・中止（終わったもの全部）」です。フィルターの状態には、「完了（やった）」だけ・「中止（キャンセル）」だけ、もあります。
  - **繰り返しの予定**では、メニューが「この回を中止にする（スキップ）」になり、押すと次の回へ進みます（完了のときと同じ動きで、完了日は付きません）。
  - 戻すとき: メニューの「中止を戻す」。まとめて操作（複数選択）でも、中止にできます（元に戻すも使えます）。
  - 完了したメモは、先に完了を戻してから、中止にします。ノートは、中止にできません。
- **振り返り（完了・中止のあとの、ひとこと）**: 終わった予定やタスクに、「晴天で、祖母も来て、楽しかった」のような、ひとことを残せます。**メモの末尾の、`## 振り返り` という見出しの下に、日付つきの行で書きます**（見出しは、1つに決めておくと、あとで、集めやすい）。
  ```markdown
  ## 振り返り
  - 2026-10-25 晴天で、祖母も来て、楽しかった。
  ```
  - **「一段落して次へ（完了にしない）」**（メモのメニュー）: 1つのタスクを、続いていく流れとして使うための操作です。振り返りへ `- 日付 ✓ ` の行を足し、期日を次の区切り（明日・来週の月曜・1週間後・日付を選ぶ）へ進めて、行の続きにカーソルを置きます。「下書き完了 → 次: 清書」のように書くと、経緯が残ります。完了にするのは、流れ全体が終わったときだけ。サブタスクを先に作らなくて済みます。完了日（実績）には数えません。繰り返しのメモは、ふつうの完了が同じ働きをするので、出ません。
  - **「振り返りを書く」**（メモのメニュー）: 末尾に、`## 振り返り` と、今日の日付つきの行を足して、その行にカーソルを置きます。すでに見出しがあれば、その節の末尾に、新しい行を足します。
  - **完了・中止にした直後**に、小さく「振り返りに残しますか？ [振り返りを書く]」と出ます（15秒で消えます）。**まとめて操作のときと、ノートには、出ません。** 邪魔なときは「今後は出さない」で、オフにできます（メモのメニューの「完了後の『振り返り』の案内」で、またオンにできます）。
  - 完了した日時は、アプリが自動で記録します。振り返りの日付は、「書いた日」で足ります。
  - **繰り返しのタスク・予定は、回の記録が、自動で残ります。** 完了すると（通知の「完了」ボタンでも）、期日が次の回へ進むと同時に、`## 振り返り` の末尾に、`- 2026-10-25 ✓` の行が、1行付きます。この回を中止にした（スキップした）ときは、`- 2026-10-25 中止` です。繰り返しは、メモが終わらず、完了日（`completed:`）が残らないので、**この行が、各回の実績の記録**です。同じ日・同じ印の行は、二重になりません。
  - そのあと「振り返りを書く」を押すと、**自動の行の続き**（`- 2026-10-25 ✓ ` のあと）に書けます。
  - **`## 振り返り` の節の中の日付は、日付として読みません。** すでに終わったことの記録なので、「今日」の一覧・カレンダーの「本文の日付」・期日の提案・通知には、使われません（節は、次の見出しの前までです）。
  - 中止のときも、同じ見出しで、**やらなかった理由**を残せます（例: 「雨で中止。来月に延期」）。
  - 振り返りを書いたメモだけを見たいときは、フィルターで「本文に含む文字: 振り返り」を作ります。

### 本文の日付・時刻を、自動で拾う
- メモを書くと、本文の日付が「本文の日付」として索引に入り、カレンダーに出ます（期日にはなりません）。
- 読める書き方の例:
  - 日付: `10/8` `10月8日` `2026/10/8` `明日` `明後日` `来週火曜` `来週の日曜` `今週金曜` `金曜日`
  - 時刻: `15時` `午後3時半` `18:30` `夜8時` `お昼` `朝` `夕方` `正午` / 時刻の範囲: `17:00-19:00` `17時から19時`
  - 日付の範囲: `10/12〜10/14` `10/12-14` `10月12日から14日まで`
- 時刻の印が無い「N時」は、1〜6時 → 午後、7〜11時 → 午前とみなします。
- 日付の次の行が `17:00-19:00` のように始まっていれば、その時刻もその日付の時刻になります。
- URL・コードブロック・タグ・英数字に挟まれた数字は読みません。
- **提案（💡）**: 期日がまだ無く、今日以降の日時が本文にあるとき、整形表示の上に出ます。
  - 「〜に」「17:00-19:00」「10/12〜10/14」→ **[予定にする]**（時刻つきなら、開始の10分前に通知）
  - 「〜まで」「締切」→ **[期日にする]**
  - [×] で、そのメモでは、その提案を出さなくなります。
  - 日時が5つ以上あるメモ（メール・ログなど）には、出しません。
  - 自動では、期日にしません（読み違いがあり得るため、押したときだけ反映）。

### 複数日
- メモのメニュー →「複数日（〜まで続く）」→「終わりの日を選ぶ…」。いまの期日が**開始日**、選んだ日が**終わりの日**になります。「1日だけに戻す」で戻せます。
- 複数日のメモを別の日へドラッグ / メニューで日付を選ぶと、**長さを保ったまま**動きます（選んだ日が開始日）。

### 繰り返し（毎日・毎週・毎月・毎年）
- メモのメニュー →「繰り返し」: 毎日 / 平日（月〜金）/ 毎週（期日の曜日）/ 隔週 / 毎月（期日の日）/ 毎月末 / 毎年。メニューの「繰り返さない」でやめられます。期日があるメモだけで使えます。
- **完了にすると、完了ではなく、期日が次の回に進みます**（メモは消えず、未完了のまま、次の日付になります）。
  - 時刻・リマインダー・予定の印・終わりの時刻・複数日の長さは、そのまま引き継ぎます。
  - 遅れて完了したときは、過ぎた回を飛ばして、今日以降の最初の回に進みます（毎日のものを3日遅れて完了すると、今日になります）。早く完了したときは、期日の次の回です。
  - 通知の「完了」ボタンでも、同じように次の回に進みます。
  - 「次の回: 11/11（毎月11日）」と、画面の下の表示に出ます。
- 一覧には 🔁 が付きます。メモを開くと、期日の横に「🔁 毎週 火」と出ます。
- 本文に「毎週火曜」「毎月10日」「毎日」「平日だけ」「隔週」「毎年10月11日」「月末」「3日ごと」と書くと、💡が「繰り返しにする」と提案します。押すと繰り返しになり、期日が無ければ、今日以降の最初の回が期日になります。
- 月カレンダー（大）には、今後の回が**薄い点線の帯**で出ます（見るだけです。ドラッグはできません。メモとして先に作られるわけではありません）。
- TickTick から取り込んだ繰り返し（毎月◯日）は、そのまま使えます。
- まだ扱えない決まり: 「第2火曜日」のような位置指定、「完了した日から数える」。

### リマインダー（通知）
- ⏰ ボタン、またはメモの右クリック →「リマインダー」: 期日の時刻に / 5・10・30分前 / 1時間前 / 前日… / 通知しない。複数選べます。
  - 表示は「何日前の何時」で出ます。終日の期日は「7日前の朝9:00」「前日の朝9:00」「当日の朝9:00」、時刻つきは「10分前」「1時間30分前」「6日15時間前」のように読めます（TickTick から取り込んだ長い設定も、同じ形で読めます）。
- 終日の期日は、当日の朝9:00 に通知します。
- 🔔（または ☰ メニューの「通知の設定」）で、この端末の通知を有効にします（端末ごとに1回。Android 13 以降は「通知を許可」も）。通知は、アプリを閉じていても届きます（PC のサーバーが動いているとき）。
- 通知には「完了」「10分後」のボタンが付きます。タップすると、そのメモが開きます。
- PC が止まっていた間に過ぎた通知は、起動後に遅れて届きます（24時間分まで）。

## 10. 一覧・検索・並べ替え
- **検索**: `/`（編集中以外）で検索欄へ。空白で区切ると、全部を含むメモ（AND）。日本語の一部分でも見つかります。
- **メニュー**: すべて / 今日 / 次の7日間 / 期限切れ / 日付なし / 完了・中止 / ゴミ箱。「完了・中止も一覧に出す」で、完了も混ぜられます。
- **並び順**（一覧の上の「並び: …」）: 更新日 / 作成日 / 期日 / 優先度 / **完了日** / 題名 / **タグ**（最初のタグの名前順。タグ無しは後ろ） / 手動。
  - **完了日**: 完了にした日時で、新しい順に並びます（「完了・中止」の一覧で使うと便利です。ピン留めは先頭のまま。中止は数えません）。
  - 完了したメモは、一覧に「✓完了 26/10/13」と出ます（マウスを乗せる / メニューで、時刻まで）。完了日は、あとから本文を直しても変わりません（更新日は変わります）。TickTick から取り込んだ完了日も入っています。
  - 手動: メモを**ドラッグ**して好きな位置へ（行の上半分 = その上、下半分 = その下）。スマホは、メモのメニュー →「並べ替え」（先頭へ・1つ上へ・1つ下へ・末尾へ）。順番は全端末で共通。
- **日付の表示**は `26/10/11` の形（マウスを乗せる / メニューで、作成・更新の日時の詳細）。
- **複数選択・まとめて操作**:
  - **選択モード（スマホ向け。PC でも使えます）**: 一覧の上の「☑」を押す（または、メモを長押し →「複数選択を始める」）と、選択モードになります。メモを**タップ**すると、選んだ印（✓）が付きます（もう一度タップで外す）。上のバーに「3件 選択中」が出て、「すべて」で一覧のメモを全部選べます。「まとめて操作 ▾」で、下の一覧のメニューが開きます。終わったら「終了」（または ☑ をもう一度）。選択モードの間は、タップしてもメモは開きません。
  - PC の場合: 一覧のメモを `Ctrl`+クリック（Mac は `Cmd`+クリック）で1件ずつ追加・解除、`Shift`+クリックで範囲を選びます。選んだ行は、色が変わり、右に ✓ が付きます。一覧の上に「3件 選択中」と出ます（数えるのは、✓ の付いた行だけです）。選んでいる間は、いま開いている行の強調は消えます。最初の `Ctrl`+クリックでは、いま開いているメモも、選びに含まれます。ふつうのクリック（メモを開く）をすると、選択はやめます。`Esc` でも解除できます。
  - **まとめてドラッグ**: 選んだ行のどれかを掴んで落とすと、選んだ全部が同じ操作を受けます（左のリスト・タグ・「今日」などの項目・カレンダーの日・画面下の落とし先）。カーソルには「📄 3件」と出ます。選んでいないメモを掴んだときは、そのメモだけが動きます。
  - **まとめてのメニュー**: 選んだ行を右クリック、または「まとめて操作 ▾」: 完了にする・戻す / リスト / タグを付ける / 期日 / 優先度 / 種類 / ピン留め / ゴミ箱へ。`x` キーで、まとめて完了にもできます。
  - **元に戻す**: まとめて操作をすると、画面の下に「3件: … [元に戻す]」が出ます（25秒）。`Ctrl+Z`（Mac は `Cmd+Z`）でも戻せます。戻せるのは、リスト・タグ・期日（予定・通知・繰り返しも）・優先度・種類・ピン留め・完了・ゴミ箱です。ゴミ箱から戻すのは、オンラインのときだけです。
  - ゴミ箱へのまとめての移動は、確認が出ます。まとめての操作では、締切・予定の**自動振り分けは働きません**（仕分けのつもりで選んでいるため）。手動の並べ替えは、複数件では使えません（1件ずつ）。
- **ピン留め**（`p`）: 一覧の先頭に固定。**完了**（`x`、または左の○）。**優先度**（右クリック →「優先度」: 高・中・低。○の枠が赤・橙・青に）。

## 11. カレンダー
### 📆 カレンダー（左のペインに出る小さなカレンダー）
- 日を選ぶと、その日のメモが一覧に出ます。「日付なし」タブで、まだ日付が無いメモを出し、日へドラッグできます。
- 表示する日付の種類: 期日＋本文の日付 / 期日だけ / 作成日 / 更新日 / **完了日**。
  - 「完了日」にすると、**いつ何を完了したか**が、カレンダーに出ます（完了にした日のマスに、完了したメモが並びます。日を選ぶと、その日に完了したメモの一覧）。日付の種類を「完了日」にしている間は、「完了・中止も一覧に出す」の設定に関わらず、完了したメモが対象です。
- `[` `]` で前の月・次の月。`c` で開く。

### 🗓 月カレンダー（大）
- 窓いっぱいの月表示（月曜始まり）。上のボタンで、**月 ⇄ 週**、前へ・今日・次へ（`[` `]` も）、日付の種類の選択（「完了日」にすると、帯の先頭に、完了した時刻が出ます）。
- メモは、日付のマスに**帯**で並びます。時刻つきは時刻が先頭（`17:00-19:00 題名` のように）。帯の色は、タグの色。完了したものは薄く、取り消し線。
- 複数日のメモは、**週ごとに1本の長い帯**（週をまたぐときは ◀ ▶）。
- 土曜は青、日曜と**祝日**は赤。祝日名も出ます（日本の祝日・振替休日・国民の休日を、計算で出します）。
- 帯を**押す** → 右にメモが開く（「× 閉じる」で閉じる）。帯を**右クリック**（スマホは長押し）→ メモのメニュー（完了・期日・タグ・ゴミ箱など）。
- 帯を**別の日のマスへドラッグ** → 期日が移る（時刻は保たれる）。
- 空いているマスを**ダブルクリック** → その日が期日の新しいメモ。上の「＋」は、今日が期日の新しいメモ。
- 1マスに入りきらないときは「+N件」。押すと、その日を、小さいカレンダーで開きます。

## 12. メニュー（右クリック・長押し）
メモを右クリック（スマホは長押し）、または上のバーの「⋯」、または `.` / `Shift+F10`:
完了にする / 中止にする / 種類（タスク・ノート） / ピン留め / 優先度 / 手動で並べ替える / 期日 / 予定にする・締切に戻す / 複数日 / 時刻 / リマインダー / リスト / タグ / 編集 / ファイルを添付 / リンクにタイトルを付ける / コピー / 履歴 / ゴミ箱へ

## 13. ゴミ箱・履歴・戻す
- **ゴミ箱へ**: `Alt+Backspace`、またはメニュー。**完全には消えません**（ファイルがゴミ箱フォルダに移るだけ）。
- 左のメニューの「🗑 ゴミ箱」→ 一覧 → 押すと中身が読める →「元に戻す」で、元の場所へ（他の端末にも届く）。オンラインのときだけ使えます。
- 完全に消す機能は、事故を防ぐため、意図的に作っていません。
- **履歴**（`Alt+H`）: そのメモの過去の版が、git の履歴から見られます（`↑↓` で選び、`Enter` で本文に戻す）。
- 複数の端末で同じメモを同時に編集して、ぶつかったときは、**あとから保存した側が、別のメモとして残ります**（書いた内容は消えません）。

## 14. Chrome から追加する（拡張機能「tick_clone に追加」）
- Chrome で開いているページの、選んだ文章・ページ・リンク・画像を、**右クリック →「tick_clone に追加」**で、新しいノートにできます（TickTick の「Add To TickTick」と同じ使い方）。ツールバーのボタンを押すと、いま開いているページを追加します。
- できるノートは、1行目 = ページのタイトル / 2行目 = URL / 続けて、選んだ文章 / 末尾に `#共有`（種類は「ノート」）。画像は、添付として保存され、本文に表示されます。
- 追加できたかどうかは、画面の右下の通知で分かります。
- **入れ方**（1台ごとに1回）:
  1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
  2. 「パッケージ化されていない拡張機能を読み込む」を押し、フォルダを選ぶ。
     - このリポジトリの `extension` フォルダ（別の PC では、そのフォルダをコピーして使います）
  3. 右クリックのメニューに「tick_clone に追加」が出れば完了です（出ないときは、ページを開き直す）。
- **送り先**: 先に、拡張機能の「オプション」に入れたアドレス（例: `https://<PC名>.<tailnet名>.ts.net`）、だめなら `http://localhost:8765`（この PC）の順に試します（オプションに「つながるか試す」もあります）。
- Mac から使うには、Mac にも **Tailscale** を入れて、同じアカウントで入る必要があります（入れていないと、「追加できませんでした」と通知が出ます）。
- 送るのは、右クリックで選んだ内容だけで、送り先は自分の tick_clone だけです。

## 15. OS の「共有」から送る
- スマホのブラウザやアプリの「共有」→ tick_clone を選ぶと、タイトル・文章・URL が、新しいメモ（タグ `#共有`）になります。
- ホーム画面に追加したアプリ（PWA）で使えます。

## 17. バックアップ・保存場所（運用メモ）
- メモ: `data/notes/`（年/月/ID.md）。ゴミ箱: `data/trash/`。添付: `data/attachments/`。場所は、環境変数 `TICK_DATA` で変えられます。
- `data` は、それ自体が git のリポジトリで、変更のたびに自動で記録されます（約5秒後）。
- **バックアップ**: `python tools/backup.py --dest <保存先フォルダ>`（環境変数 `TICK_BACKUP_DIR` でも指定できます）。メモ＋git の zip を14世代、添付は差分で保存します。毎日動かすには、タスクスケジューラ（Windows）や cron に登録します（README を参照）。
- 索引（`data\index.db`）は、消えても作り直せます。通知の鍵（`data\push\`）は、バックアップに入れていません。
- サーバーの起動: `start.bat`（Windows）/ `start.sh`（Mac・Linux）。PC の起動時に自動で立ち上げる設定は、README を参照（ポートは 8765）。
- **注意**: 8765 を、ほかのアプリが先に使うと、tick_clone が立ち上がれません。

## 18. できないこと・注意
- **既定では、ログイン機能はありません。** 自分の端末だけが、開ける状態で使ってください（`127.0.0.1` のままにするか、Tailscale のような自分の端末だけの回線を使う）。**インターネットへの公開（Tailscale Funnel、ポート開放など）は、絶対にしないでください。** メモが、誰にでも読めて、書き換えられてしまいます。
- **念のための鍵（任意）**: 環境変数 `TICK_TOKEN` を決めて起動すると、トークンを知っている人だけが使えます。ブラウザは `/login` でトークンを入れて入ります（1年間、覚えます）。Chrome 拡張は、オプションの「アクセストークン」に入れます（この端末の中だけに保存）。設定しなければ、認証なしのままです。トークンは1つだけで、通信を暗号化しないので、HTTPS 越し（`tailscale serve`）で使ってください。
- 完全削除（ゴミ箱を空にする）はありません。
- メモ同士のリンク（`[[…]]`）は、まだありません。
- 日付の読み取りは、完全ではありません。メール・ログのような文章は、読み違えることがあります（提案として出すだけです）。
- スマホ実機での確認が、まだ十分でない機能: 月カレンダー（大）の複数日の帯、予定・複数日まわり。

## 19. 困ったとき
| 症状 | 対処 |
|---|---|
| 画面が古い・新機能が出ない | ブラウザを更新（アプリは自動で新しい版に切り替わります）。それでも変なら、サイトのデータ（Service Worker・キャッシュ）を消す |
| 開けない・つながらない | PC が起動しているか確認。サーバーが止まっているときは、`server.log` を見る。ポートの取り合いのときがある |
| スマホで通知が来ない | 🔔 で有効にしたか、Chrome の通知がオンか、電池の節約で Chrome が止められていないか |
| 変更が他の端末に出ない | 画面右上の接続表示（オンライン/オフライン）を見る。オフラインなら、つながったときに自動で送られる |
| 間違えて消した・変えた | ゴミ箱から戻す / 履歴（`Alt+H`）から戻す / git の履歴（data フォルダ） |
