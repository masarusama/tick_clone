# tick_clone 使い方（ヘルプ・機能一覧）

最終更新: 2026-11-21（画面の版 v68）
（この文書を直したら、`python tools/build_help.py` でアプリ内のヘルプも更新する）
このページと同じ内容が、アプリの中でも読めます（キーボードの `?`、左メニューの「❓ 使い方」、`Ctrl+K` →「使い方」）。

---

## 1. これは何か
- メモ・タスクアプリ（TickTick のような使い心地を目指した、自分の PC で動かす自作アプリ）。メモ1件 = Markdown ファイル1つ。
- 検索や一覧を速くするための「索引」（SQLite）は、メモのファイルからいつでも作り直せます。**正本はメモのファイル**です。
- 自分の PC で動くサーバーに、PC・スマホ・Mac のブラウザからつなぎます（Tailscale などの、自分の端末だけの回線の中。インターネットには公開しません）。
- 一度開けば、**オフラインでも使えます**。変更は端末に先に保存され、つながったときに自動で同期されます。

## 2. 開く場所・使い始め
| 端末 | 開き方 |
|---|---|
| この PC | http://localhost:8765/ |
| スマホ・Mac など（Tailscale に入れた端末） | `https://<PC名>.<tailnet名>.ts.net/`（`tailscale serve` で出したアドレス） |

- スマホは、Chrome のメニュー →「ホーム画面に追加」で、アプリのように使えます。
- PC の電源が入っていて、サーバーが動いているときだけ、新しい内容が同期されます（サーバーは PC の起動時に自動で立ち上がります）。

## 3. 画面の見方
- **左**: メニュー（すべて・今日・次の7日間・期限切れ・日付なし・ノート・カレンダー・月カレンダー（大）・完了・ゴミ箱）と、リストの一覧、**フィルター**の一覧、タグの一覧。
- **中**: メモの一覧（上に検索欄・並び順）。**アプリを開いたときは「次の7日間」**が出ます。一覧の上の見出し（「次の7日間 (3) ▾」など）を押すと、画面（すべて・今日・期限切れ・ノート・カレンダーなど）を切り替えるメニューが開きます（左のメニューと同じ項目。スマホでも使えます）。
- **右**: 開いているメモ。上のバーに、日付・⏰・🔔・📎・整形表示/編集・履歴・⋯・＋新規。
- PC では、一覧の上の「＋ 新しいメモ」ボタンで新規メモを作れます。
- スマホは、一覧とメモが別画面です。左上の ☰ でメニュー、右下の ＋ で新規メモ、「‹ 一覧」で戻ります。
- **スマホの「戻る」ボタン（Android）**: アプリの外へ出ずに、いまの画面を**1つ閉じます**。順番は、拡大画像 → メニュー・ダイアログ（使い方・履歴・通知など）→ 選択モード → ☰ メニュー → 開いているメモ（→ 一覧へ）→ 絞り込み・検索・別の画面（→起動時の画面「次の7日間」へ）です。何も閉じるものが無い（「次の7日間」の一覧にいる）ときに押すと、アプリが閉じます。PC のブラウザの「戻る」は、いままでどおりです。

## 4. メモを書く
- **整形表示のまま書けます**。文字をクリックすると、その行だけが入力欄になります。
  - `Enter`: 次の行へ（箇条書き・チェックボックス・番号は続けて作る。空の項目で Enter なら終わる）
  - `Backspace`（行頭）: 前の行とつなぐ（記号つきの行は、まず記号だけ外れる）
  - `↑` `↓`（行頭・行末）: 隣の行へ
  - `Esc`: 入力を抜ける
- **全文をソース（文字だけ）で編集**したいときは、`Alt+P` か `e`。もう一度押すと整形表示に戻ります。
- 書き方（Markdown）: `# 見出し` / `- 箇条書き` / `- [ ] チェックボックス` / `1. 番号` / `> 引用` / バッククォート3つで囲むとコードブロック / `[題名](URL)` リンク
- **コピー・切り取り・貼り付け**（`Ctrl+C` `Ctrl+X` `Ctrl+V`。Mac は `Cmd`）:
  - 行を入力しているとき（行をクリックした状態）、またはソース編集のときは、ふつうのテキスト欄と同じです。右クリックのメニューも使えます。
  - 整形表示のまま、**行をまたいで文字を選ぶ**（ドラッグ）と、`Ctrl+C` で、記号つきの元の Markdown の行（`- [ ]` なども含む）がコピーされます。`Ctrl+X` なら、選んだ行を丸ごと切り取ります。
  - `Ctrl+A` は、整形表示の本文を全部選びます（そのまま `Ctrl+C` で、メモ全体をコピー）。
  - 整形表示のまま `Ctrl+V` すると、貼り付けた文が行として、選んでいる行の次（選んでいなければ末尾）に入ります。画像は、添付になります。
  - 1行の中の一部だけを選んだときは、見た目の文字がコピーされます。切り取りたいときは、その行をクリックして入力に入ってから `Ctrl+X`。
- **チェックの行（☐）を作る**: 整形表示のまま作れます（ソース編集に切り替えて `- [ ] ` と打つ必要は、ありません）。
  - 行の頭で **`[]` と打って、空白**。`[ ]` でも `- []` でも作れます。日本語入力のときの **`「」`** でも作れます。
  - 上のバーの **☑** ボタン。行を書いているときは、**その行**を ☐ にします（もう一度押すと、戻ります）。どの行も書いていないときは、**末尾に新しい ☐ の行**を足して、書き始めます。
  - **`Alt+C`**。同じ働きです（もう一度で戻ります）。
  - 箇条書き（・）や番号の行で ☑ / `Alt+C` を押すと、☐ に変わります（記号は重なりません）。
  - ☐ の行で `Enter` を押すと、**次の行も ☐** になります。空のまま `Enter` で、終わります。
- 同じように、行の頭で `- ` と打つと箇条書き、`1. ` と打つと番号になります（打ったとたんに、記号が本物の部品に変わります）。戻すときは、行の頭で `Backspace`。
- ☐ ☑ は、クリックで切り替えます。
- 末尾の余白をクリックすると、書き足せます。
- **保存は自動**です（打つのをやめて約1秒後）。`Ctrl+S` で今すぐ保存。
- **URL を貼る**と、数秒後にページのタイトルつきのリンクになります。文字を選んでから URL を貼ると、その文字がリンクの題名になります。メモの右クリック →「リンクにタイトルを付ける」で、メモ中の URL をまとめて変換します。
- **画像・PDF**: メモの上にドロップ / `Ctrl+V` / 📎 ボタン。本文に表示され、下にも並びます。SVG（図・手書きなど）も画像として表示されます（安全のため、SVG を直接開くとダウンロードになります）。

## 5. リスト（TickTick と同じ「箱」）
- メモは、**1つのリスト**に入れられます（タグと違い、複数には入れません）。リストに入れていないメモは「📥 受信箱」です。
- 左のメニューの「リスト」欄に、受信箱・リストが並び、件数が出ます。押すと、そのリストのメモだけが一覧に出ます（もう一度押すと戻る）。
- 「フォルダ/リスト」の形（例: `仕事/営業`）で、フォルダにまとめられます（2階層まで）。フォルダを押すと、中のリストをまとめて表示します。▾ で開閉します。
- 入れ方: メモを左の**リストへドラッグ**（受信箱へ落とすとリストが外れます）/ メモのメニュー →「リスト」/ 上の「＋」で新しいリストを作って、開いているメモを入れる。
- 上の「＋」で、**空のリスト**を作れます（`仕事/営業` のようにフォルダ付きの名前も可）。メモは、あとからドラッグ / メニューで入れます。
- **並び順は、自分で決められます**。リストの行を**ドラッグ**して、好きな位置へ（行の上半分に落とすとその上、下半分ならその下。フォルダは、中のリストごと動きます。フォルダの中のリストは、同じフォルダの中でだけ動きます）。スマホなど、ドラッグできない端末は、リストを右クリック（長押し）→「先頭へ」「1つ上へ」「1つ下へ」。並び順は全端末で共通です。決めていないリストは、名前順で後ろに付きます。
- **締切・予定にしたとき、自動でリストに入れる**（任意の設定）: リストを右クリック →「締切にしたメモを、自動で入れる」「予定にしたメモを、自動で入れる」。たとえば、締切（〜まで）は Oneday、予定（〜に）は「具体的な次にとるべき行動」にしておくと、💡の「締切にする」「予定にする」を押したときや、メモのメニューで「予定にする」「締切に戻す」を選んだとき、**日付ピッカーで日付を選んだとき**（上のバーの📅の日付欄、メニュー →「日付」→「日付を選ぶ…」）に、そのリストへ入ります。日付ピッカーでは、予定の印が付いているメモは「予定」の、付いていなければ「締切」の入れ先になります。
  - **日付を指定して新規作成したとき**（カレンダーの日を選んで書く・「今日」の一覧で書く・日付欄で日付を選んでから書く）も、リストを選んでいなければ、締切の入れ先（Oneday。7日以内なら具体的な次…）へ入ります。
  - **リストが未設定（受信箱）のメモだけ**が対象です。手でリストを決めたメモは動きません。「締切に戻す」で、リストを入れ直すこともしません。
  - 「今日」「明日」などの項目や、ドラッグで日付を入れたときは、自動では入りません（その日に動かすだけで、仕分けではないため）。もう一度同じ項目を選ぶと、設定が外れます。
- **ノートにしたとき、自動でリストに入れる**: リストを右クリック →「**ノートにしたメモを、自動で入れる**」。たとえば「資料そもそも行動できないよ」に設定すると、**ノートにした瞬間に、そのリストへ入ります**。
  - 働くとき: メニューの「種類」でノートにしたとき（まとめて操作でも）/ `Shift+N` で新しくノートを書いたとき / Chrome 拡張やスマホの共有で入れたメモ（共有されたものは、ノートとして入ります）。
  - ここでも、**リストが未設定のメモだけ**が対象です。手でリストを決めたメモや、リストを選んでから書いたメモは動きません。
- **ノートに日付を付けてタスクになったときも、自動で入れる**: 「ノートにしたメモを、自動で入れる」リスト（例: 資料）にあるノートに、日付を付けた瞬間（日付ピッカー・💡の提案・メニューの日付・「今日」「明日」へのドラッグなど、どの経路でも、新規でも更新でも）、タスクになると同時に、**予定の印があれば「予定」の入れ先、無ければ「締切」の入れ先**へ移ります（例: 予定 → 具体的な次にとるべき行動、締切 → Oneday。締切が7日以内なら、最初から具体的な次へ）。
  - 対象は、そのリスト（資料）に入っているノートだけです。手で別のリストに入れたメモ、もともとタスクのメモは動きません。まとめて操作（複数選択）では働きません。
  - **逆向き（日付を外したとき）**: 未完了のタスクの日付を外して、メモが「締切・予定の入れ先」（Oneday・具体的な次…）にあるときは、「ノートに戻して、リスト『資料』へ入れますか？」と**確認**が出ます。「OK」でノートに戻って資料へ、「キャンセル」ならタスクのままです（手でそのリストに入れたこともあるため、確認つきです）。完了済み・繰り返しのメモ、まとめて操作では出ません。
- **このリストに入れたメモは、自動でノートにする**（逆向きの自動）: リストを右クリック →「このリストに入れたメモは、自動でノートにする」。たとえば「資料そもそも行動できないよ」に設定すると、**そのリストへ入れた瞬間に、メモがノートになります**（ドラッグ・メニュー・まとめて操作・自動振り分けのどれでも）。そのリストを開いて `n` で新しく書いたメモも、ノートです。
  - 対象は、**日付の無い未完了のタスクだけ**です。日付つきのタスク（予定の印つきを含む）や、完了済みのものは、タスクのまま入ります（勝手に締切を外さないため）。
  - 設定したとき、いまそのリストにある、対象のタスクにも当てはめるか聞きます（「元に戻す」で戻せます）。もう一度同じ項目を選ぶと、設定が外れます。
- **締切が近づいたら、別のリストへ移す**: リストを右クリック →「締切が近づいたら、別のリストへ移す」→ 移し先を選び、「締切が 3 / 7 / 14 / 30 日以内になったら」を選びます（目安は 7 日）。たとえば、Oneday から「具体的な次にとるべき行動」へ。
  - **アプリを開いたとき、1日に1回**、そのリストの中の、**日付が付いた未完了のタスク**で、締切が決めた日数以内（期限切れも含む）のものを、移し先へ移します。ノート・完了したもの・日付の無いものは、動きません。
  - 移したあとは、「3件: 締切が7日以内になったので…移しました [元に戻す]」が出ます。
  - 日付ピッカーなどで、すでに近い締切を付けたときは、「締切を自動で入れる」リスト（Oneday）ではなく、**最初から移し先**へ入ります。
  - 「移すのをやめる」で、設定を外せます。
- リストを右クリック →「名前を変える…」で、そのリストのメモ全部の名前が変わります。「リストを削除…」で、リストを消せます（中のメモは消えず、受信箱に戻ります）。
- 一覧で、リストを選んでいないときは、メモの行にリスト名（📋）が出ます。リストを選んでから新規メモを作ると、そのリストに入ります。
- TickTick から取り込んだメモは、元のリスト（Inbox・Someday など）に入っています。

## 6. タスクとノート（TickTick と同じ区別）
- メモには **種類** があります。**タスク**（○で完了できる。日付・繰り返し・通知が使える）と、**ノート**（読み物・資料。○は付けず、📝 の印が出る）です。
- 一覧では、タスクは○、ノートは 📝 が左に付きます。ノートは、完了にできません（`x` を押しても、案内が出るだけ）。「期限切れ」にも出ません。
- 左のメニューの「📝 ノート」で、ノートだけを一覧にできます。
- 切り替え: メモのメニュー →「種類」→ タスク / ノート。ノートに**日付を付けると、タスクになります**（日付はタスクのものなので）。
- **ノートは、日付（日付・予定・繰り返し）を持ちません。** ノートに日付を付けると、タスクになります。日付つきのメモを「ノートにする」と、確かめてから日付を外します（「元に戻す」で戻せます）。本文に書いただけの日付は、そのままカレンダーに出ます。
- 新規メモ: `n`（または「＋ 新しいメモ」）の種類は、場所で決まります。**リストを選んでいない「すべて」・受信箱・ノート・日付なしなどでは、ノート**（書くときは仕分けしない。日付を付けると、タスクになります）。リストを選んでいるときは、そのリストの設定（なければタスク）。日付を扱う画面（今日・期限切れ・カレンダー）では、タスク（起動時の「次の7日間」では、ノート）。`Shift+N` = いつでもノート、`Alt+T` = いつでもタスク。「今日」の一覧で作ると今日の日付、カレンダーで日を選んでいるときはその日の日付が付きます。
- リストを右クリック →「新しいメモの種類: ノート」にすると、そのリストで `n` を押したときも、ノートが作られます（読書メモ用のリストなど。TickTick の「ノート用のリスト」と同じ使い方です）。
- 取り込んだメモは、TickTick の区別のままです（タスクは○あり、ノートは📝）。

## 7. フィルター（保存した絞り込み）
- 条件を組み合わせた絞り込みに名前を付けて保存し、左のメニューの「フィルター」欄から、1回押すだけで開けます（件数も出ます）。TickTick の「フィルター」と同じ使い方です。
- **作る**: 「フィルター」の右の「＋」 → 名前を付けて、条件を足します。「いまの条件に当てはまるメモ: N 件」が、その場で出ます。
- **条件の種類**: リスト（受信箱も）/ タグ（親タグは子も含む）/ 優先度 / 種類（タスク・ノート）/ 状態（未完了・完了）/ 日付（今日・明日・7日以内・期限切れ・なし・あり）/ 予定・締切 / 題名に含む文字 / 本文に含む文字（空白で区切るとすべて含む）/ ピン留め / 完了した・作成した・更新した（○日以内）。
- **組み合わせ**: 「すべて満たす（かつ）」か「どれかを満たす（または）」。各条件は「含む」か「除く」を選べます（例: 題名に「日記」を含む、かつ、完了を除く）。
- **直す・並べる**: フィルターを右クリック（スマホは長押し）→ 編集 / 複製 / **当てはまるメモを、自動でリストへ入れる** / 1つ上へ・1つ下へ / 削除。フィルターは、全端末で共通です。
- **フィルターのルール（当てはまるメモを、自動でリストへ入れる）**: たとえば「`#日記` を含む」フィルターに「資料そもそも行動できないよ」を設定すると、**リスト未設定のメモが、その条件に当てはまった瞬間**（本文にタグを書いて保存したとき、タグを付けたとき、ノートにしたときなど）に、そのリストへ入ります。ほかに、**アプリを開いたとき（1日1回）**にも、リスト未設定のメモをまとめて当てはめます（Chrome 拡張などで入ったメモも、ここで入ります）。
  - 設定したとき、いま受信箱にある当てはまるメモにも、当てはめるか聞きます（「元に戻す」で戻せます）。
  - **リスト未設定のメモだけ**が対象です。手でリストを決めたメモは動きません。「締切・予定・ノート」の自動振り分けが先で、当てはまらなかったときに、フィルターのルールが働きます。複数のフィルターに当てはまるときは、**一覧で上にあるフィルター**が優先です。
- 状態（完了・未完了）や「完了した（○日以内）」の条件が無いフィルターでは、ふだんの一覧と同じく、完了したメモは除きます（「完了・中止も一覧に出す」で、含められます）。フィルターの編集画面の「**完了・中止したメモも含める**」にチェックを入れると、そのフィルターは、完了したメモも含めて出します（日記のように、完了にしたものも見たいとき）。
- 選んだフィルターの中でも、並び順・検索・複数選択・ドラッグは、これまでどおり使えます。

## 8. タグ
- 本文に `#仕事` と書くとタグになります。`#` を打つと候補が出ます（`↑↓` と `Tab`/`Enter` で確定）。
- `#本/小説` のようにスラッシュで区切ると、親子のタグ（親の `#本` を選ぶと、子のメモも出ます）。
- 左のタグを**右クリック → 色**を選ぶと、一覧のタグも帯も同じ色になります（色は全端末で共通）。
- 一覧のメモを、**左のタグへドラッグ**すると、そのタグが付きます。
- `g`: 一覧を、タグごとのグループ表示にする／やめる。

## 9. 日付・時刻・予定・締切
### 日付を付ける
- 上のバーの 📅 の日付欄と、時刻欄（空 = 終日）。`Alt+D` で日付欄へ。
- メモのメニュー（右クリック）→「日付」: 今日・明日・来週の月曜・1週間後・日付を選ぶ…・日付を消す。「時刻」: 9・12・15・18・21 時など。
- 本文に `!10/8` や `!明日` と書いても、日付になります（! の直後だけを読みます）。
- 一覧のメモを、カレンダーの日・「今日」「日付なし」などへ**ドラッグ**しても、日付が変わります。ドラッグ中は画面の下に「今日 / 明日 / 来週の月曜 / 日付なし / 完了 / ゴミ箱」の落とし先が出ます。

### 締切と予定
- 日付は、ふつうは**締切**です。過ぎると「期限切れ」に出ます。
- **予定**にすると、過ぎても期限切れになりません（会議・ランチ・通院など）。メモのメニュー →「予定にする」。「🗓」の印が付きます。
- 予定には、**終わりの時刻**（17:00-19:00）や、**複数日**（10/12〜10/14）を持たせられます。
- **予定・タスクを中止（キャンセル）にする**: メモのメニュー →「**中止にする（キャンセル）**」。やらないことになった予定・タスクに使います。
  - メモは残り、「完了・中止」の一覧に移ります（取り消し線と ×、「🚫中止 26/10/15」と出ます）。**日付（いつの予定だったか）はそのまま残ります。**
  - **実績（完了）には数えません。** 完了日が付かないので、カレンダーの「完了日」、「完了した（○日以内）」の条件、並び順「完了日」には出ません。完了・中止の両方を含むのは、「完了・中止」の一覧と、フィルターの状態「完了・中止（終わったもの全部）」です。フィルターの状態には、「完了（やった）」だけ・「中止（キャンセル）」だけ、もあります。
  - **繰り返しの予定**では、メニューが「この回を中止にする（スキップ）」になり、押すと次の回へ進みます（完了のときと同じ動きで、完了日は付きません）。
  - 戻すとき: メニューの「中止を戻す」。まとめて操作（複数選択）でも、中止にできます（元に戻すも使えます）。
  - 完了したメモは、先に完了を戻してから、中止にします。ノートは、中止にできません。
- **振り返り（完了・中止のあとの、ひとこと）**: 終わった予定やタスクに、「晴天で、祖母も来て、楽しかった」のような、ひとことを残せます。**メモの末尾の、`## 振り返り` という見出しの下に、日付つきの行で書きます**（見出しは、1つに決めておくと、あとで、集めやすい）。
  ```markdown
  ## 振り返り
  - 2026-10-25 晴天で、祖母も来て、楽しかった。
  ```
  - **完了日を、実際に終わった日に直せます。** 完了した直後の案内の「完了日を変える」、またはメモのメニュー「完了日を変える…」から、日付を選びます（運動会が 10/17 に終わって、10/29 に完了ボタンを押した、というとき）。カレンダーの「完了日」は、直した日に出ます。**振り返りの行の日付は、書いた日のまま**です（完了日は「いつ終わったか」、振り返りの日付は「いつ書いたか」という、別の記録だからです）。この操作は本当の完了のためのもので、一段落・繰り返しの回の日付は、「完了・一段落して次へ・繰り返し（3つの違い）」の決まりで扱います。
  - **過ぎた予定の案内**: 予定（予定の印のあるメモ）は、過ぎても期限切れにならず、完了を押さないかぎり残ります。そこで、1日1回、アプリを開いたときに「過ぎた予定が N件あります」と出ます。**予定日に完了にする**（完了日が、それぞれの予定日になります）/ **中止にする**（やらなかった・行かなかった予定。実績には数えません）/ そのまま、を選べます（「元に戻す」で戻せます）。自動で完了にはしません。出席しなかった予定まで、実績になってしまうからです。リストの一覧では、過ぎた予定が薄く表示されます。
  - **「一段落して次へ（完了にしない）」**（メモのメニュー）: 1つのタスクを、続いていく流れとして使うための操作です。振り返りへ `- 日付 ✓ ` の行を足し（予定日が今日と違うときは、`- 2026-11-19 ✓（予定日 2026-11-17）` のように、予定日を添えます）、日付を次の区切り（明日・来週の月曜・1週間後・日付を選ぶ）へ進めて、行の続きにカーソルを置きます。「下書き完了 → 次: 清書」のように書くと、経緯が残ります。完了にするのは、流れ全体が終わったときだけ。サブタスクを先に作らなくて済みます。完了日（実績）には数えません。繰り返しのメモは、ふつうの完了が同じ働きをするので、出ません（3つの違いは、「完了・一段落して次へ・繰り返し（3つの違い）」へ）。
  - **「振り返りを書く」**（メモのメニュー）: 末尾に、`## 振り返り` と、今日の日付つきの行を足して、その行にカーソルを置きます。すでに見出しがあれば、その節の末尾に、新しい行を足します。
  - **完了・中止にした直後**に、小さく「振り返りに残しますか？ [振り返りを書く]」と出ます（15秒で消えます）。**まとめて操作のときと、ノートには、出ません。** 邪魔なときは「今後は出さない」で、オフにできます（メモのメニューの「完了後の『振り返り』の案内」で、またオンにできます）。**この設定は、全端末で共通**です（どれか1台で切り替えれば、ほかの端末にも、つながったときに伝わります）。
  - 完了した日時は、アプリが自動で記録します。振り返りの日付は、「書いた日」で足ります。
  - **繰り返しのタスク・予定は、回の記録が、自動で残ります。** 完了すると（通知の「完了」ボタンでも）、日付が次の回へ進むと同時に、`## 振り返り` の末尾に、`- 2026-10-25 ✓` の行が、1行付きます。この回を中止にした（スキップした）ときは、`- 2026-10-25 中止` です。繰り返しは、メモが終わらず、完了日（`completed:`）が残らないので、**この行が、各回の実績の記録**です。同じ日・同じ印の行は、二重になりません。**行の日付は、消し込んだ（振り返った）日**です。予定が実際にあった日（回の日付）と違うときは、`- 2026-11-13 ✓（予定日 2026-11-11）` のように、予定日が添えられます。予定が別の日にずれて行われたときは、消し込む前に、メモの日付を実際にやった日へ直してから消し込むと、回の日付と振り返りの日付が一致します（元の日付は「履歴」に残ります）。
  - そのあと「振り返りを書く」を押すと、**自動の行の続き**（`- 2026-10-25 ✓ ` のあと）に書けます。
  - **`## 振り返り` の節の中の日付は、日付として読みません。** すでに終わったことの記録なので、「今日」の一覧・カレンダーの「本文の日付」・日付の提案・通知には、使われません（節は、次の見出しの前までです）。
  - 中止のときも、同じ見出しで、**やらなかった理由**を残せます（例: 「雨で中止。来月に延期」）。
  - 振り返りを書いたメモだけを見たいときは、フィルターで「本文に含む文字: 振り返り」を作ります。

### 本文の日付・時刻を、自動で拾う
- メモを書くと、本文の日付が「本文の日付」として索引に入り、カレンダーに出ます（日付にはなりません）。
- 読める書き方の例:
  - 日付: `10/8` `10月8日` `15日`（月が無いときは、今日に最も近い月。「毎月15日」「15日間」「15日付」は読みません） `2026/10/8` `明日` `明後日` `来週火曜` `来週の日曜` `今週金曜` `金曜日`
  - 時刻: `15時` `午後3時半` `18:30` `夜8時` `お昼` `朝` `夕方` `正午` / 時刻の範囲: `17:00-19:00` `17時から19時`
  - 日付の範囲: `10/12〜10/14` `10/12-14` `10月12日から14日まで`
- 時刻の印が無い「N時」は、1〜6時 → 午後、7〜11時 → 午前とみなします。
- 日付の次の行が `17:00-19:00` のように始まっていれば、その時刻もその日付の時刻になります。
- URL・コードブロック・タグ・英数字に挟まれた数字は読みません。
- **提案（💡）**: 日付がまだ無く、今日以降の日時が本文にあるとき、整形表示の上に出ます。
  - 「〜に」「17:00-19:00」「10/12〜10/14」→ **[予定にする]**（時刻つきなら、開始の10分前に通知）
  - 「〜まで」「締切」→ **[締切にする]**
  - [×] で、そのメモでは、その提案を出さなくなります。
  - 日時が5つ以上あるメモ（メール・ログなど）には、出しません。
  - 自動では、日付にしません（読み違いがあり得るため、押したときだけ反映）。

### 複数日
- メモのメニュー →「複数日（〜まで続く）」→「終わりの日を選ぶ…」。いまの日付が**開始日**、選んだ日が**終わりの日**になります。「1日だけに戻す」で戻せます。
- 複数日のメモを別の日へドラッグ / メニューで日付を選ぶと、**長さを保ったまま**動きます（選んだ日が開始日）。

### 完了・一段落して次へ・繰り返し（3つの違い）
どれも「メモの日付を消し込む」操作に見えますが、**意味が違います**。迷ったら、この表で選びます。

| 操作 | メモは | 日付（次の回） | 記録 | 「完了日」ビューに |
|---|---|---|---|---|
| **完了** | 終わる（完了済みへ） | 動かない | 完了日（`completed:`）が付く | 出る |
| **一段落して次へ** | 終わらない（続く） | **自分で選ぶ**（明日・来週の月曜…） | 振り返りに `- 日付 ✓` の行 | 出ない |
| **繰り返し**（の完了・中止） | 終わらない（続く） | **決まりで自動**（毎週木曜 など） | 振り返りに `- 日付 ✓` / `- 日付 中止` の行 | 出ない |
| **完了日を変える** | 完了済みのメモだけ | 変わらない | 完了日だけを、実際に終わった日へ直す | 直した日に出る |

- **「完了」は、スッキリ終わったことだけ**に使います。流れの途中の区切り（セミ完了）は、「完了日」ビューには出しません。
- **「一段落して次へ」と「繰り返し」は、同じ種類の記録です。** 「この回を実行した」という1行が残り、違いは、次の日付を自分で選ぶか、決まりで自動に進むかだけです。
- **「完了日を変える」は、本当に完了したメモのための操作**です。一段落・繰り返しの回の日付を直したいときは、消し込む**前に**、メモの日付を実際にやった日へ直してから、消し込みます（元の日付は「履歴」に残ります）。
- **記録の行の日付は、消し込んだ（振り返った）日**です。実行した日（回の日付）が違うときは、`- 2026-11-13 ✓（予定日 2026-11-11）` のように、**予定日**が添えられます。
- **カレンダー（大）では、回の日付に出ます。** 消し込んだ回は、振り返りを書いた日ではなく、実行した日（回の日付）に、薄く出ます。完了（✓）は取り消し線、中止（スキップ）はさらに薄い波線です（クリックで元のメモが開く。ドラッグはできません）。日付の種類が「設定した日付＋本文の日付」「設定した日付だけ」のときに出ます（「完了日」には出ません）。「完了・中止も一覧に出す」の設定には関係なく、いつも出ます。
- **出るのは、`## 振り返り` の中の、`✓` か `中止` で始まる行だけ**です。手で書いただけのひとこと（`- 2026-11-13 楽しかった`）は、カレンダーには出しません。
- 「予定日」が添えられていない昔の行は、行の日付に出ます（振り返った日と、実行した日がずれていることがあります）。

### 繰り返し（毎日・毎週・毎月・毎年）
- メモのメニュー →「繰り返し」: 毎日 / 平日（月〜金）/ 毎週（日付の曜日）/ 隔週 / 毎月（日付の日）/ 毎月末 / 毎年。メニューの「繰り返さない」でやめられます。日付があるメモだけで使えます。
- **完了にすると、完了ではなく、日付が次の回に進みます**（メモは消えず、未完了のまま、次の日付になります）。
  - 時刻・リマインダー・予定の印・終わりの時刻・複数日の長さは、そのまま引き継ぎます。
  - 遅れて完了したときは、過ぎた回を飛ばして、今日以降の最初の回に進みます（毎日のものを3日遅れて完了すると、今日になります）。早く完了したときは、日付の次の回です。
  - 通知の「完了」ボタンでも、同じように次の回に進みます。
  - 「次の回: 11/11（毎月11日）」と、画面の下の表示に出ます。
- **これまでの回も、カレンダー（大）に出ます**（回の日付の日に。くわしくは、上の「完了・一段落して次へ・繰り返し（3つの違い）」）。
- 一覧には 🔁 が付きます。メモを開くと、日付の横に「🔁 毎週 火」と出ます。
- 本文に「毎週火曜」「毎月10日」「毎日」「平日だけ」「隔週」「毎年10月11日」「月末」「3日ごと」と書くと、💡が「繰り返しにする」と提案します。押すと繰り返しになり、日付が無ければ、今日以降の最初の回が日付になります。
- 月カレンダー（大）には、今後の回が**薄い点線の帯**で出ます（見るだけです。ドラッグはできません。メモとして先に作られるわけではありません）。
- TickTick から取り込んだ繰り返し（毎月◯日）は、そのまま使えます。
- まだ扱えない決まり: 「第2火曜日」のような位置指定、「完了した日から数える」。

### リマインダー（通知）
日付を付けたタスクは、決まった時刻に**通知**が届きます。アプリを閉じていても、スマホの画面を消していても届きます。「いつ鳴るか」を決めるのが**リマインダー**、「この端末で受け取る」設定が**通知の有効化**です。

**1. 何が、いつ鳴るか**
- 通知の対象は、**日付のある、未完了のタスク**です。ノート（日付を持たない）、完了・中止したメモ、日付の無いメモは、鳴りません。本文に `!10/14` と書いた日付も、対象です（終日として）。
- 何も設定しなくても、次の時刻に鳴ります。
  - 終日の日付 → **当日の朝9:00**
  - 時刻つきの日付 → **その時刻ちょうど**
  - 「予定にする」を押した、時刻つきのメモ → **開始の10分前**
- 変えたいときは、⏰ ボタン、またはメモの右クリック →「リマインダー」: 予定の時刻に / 5・10・30分前 / 1時間前 / 前日… / 通知しない。**複数選べます**（「1時間前」と「10分前」の両方、など）。
  - 表示は「何日前の何時」で出ます。終日の日付は「7日前の朝9:00」「前日の朝9:00」「当日の朝9:00」、時刻つきは「10分前」「1時間30分前」「6日15時間前」のように読めます（TickTick から取り込んだ長い設定も、同じ形で読めます）。
  - 終日と時刻つきを切り替えると、リマインダーは、既定に戻ります。
- **繰り返しのタスク**は、いまの回の分が鳴ります。完了すると、次の回の分に切り替わります。

**2. この端末で通知を受け取る（端末ごとに、1回だけ）**
1. 上のバーの 🔔（スマホは、☰ メニューの「🔔 通知の設定」）を開く。
2. 「**通知を有効にする**」を押し、ブラウザが出す「通知を許可しますか」で**許可**する。
3. 「テスト通知（いますぐ）」で、鳴るか確かめる。もう1つの「テスト通知（20秒後）」は、**アプリを閉じて（スマホは画面を消して）**から確かめるためのものです。
- 「登録済みの端末: ◯台」が、通知を受け取る端末の数です。**登録した端末すべて**に、同じ通知が届きます（PC もスマホも iPad も、それぞれで有効にします）。やめるときは、同じ画面の「この端末の通知を無効にする」。
- **Android**: Android 13 以降は、通知の許可が別に要ります。Chrome のメニュー →「ホーム画面に追加」で入れたアプリ（PWA）として使うと、確実です。
- **iPhone・iPad**: 「ホーム画面に追加」したアプリ（Safari の共有 →「ホーム画面に追加」）からだけ、通知が使えます。ふつうのタブでは、「対応していません」と出ます。
- **PC のブラウザ**: `http://localhost:8765/` でも、Tailscale のアドレス（`https://…ts.net`）でも、有効にできます。通知は `https` か `localhost` でだけ使えます。

**3. 通知の見え方**
- 1行目に **メモの題名**、2行目に「日付: 11/25 15:00 ・ 10分前」のように、日付とリマインダーが出ます（終日は「日付: 11/25（終日）・当日の朝9:00」）。
- 予定の時刻から5分以上遅れて出たときは、末尾に「**（遅れて通知）**」が付きます。
- 通知には、「**✅ 完了**」と「**⏰ 10分後**」のボタンが付きます（端末によっては、ボタンが出ないこともあります。その場合は、通知をタップして、アプリで操作します）。
  - 「完了」: アプリを開かずに、完了にします。繰り返しのタスクは、次の回へ進みます。
  - 「10分後」: 10分後に、「あとで（再通知）」として、もう一度鳴ります。
  - 通知の本体をタップすると、そのメモが開きます。
- 同じメモの通知は、重ならずに、新しい1つに置き換わります。

**4. 通知が鳴るしくみと、注意**
- 通知は、**サーバーの PC が約30秒おきに確認して、送ります**。**PC の電源が入っていて、サーバーが動いている間だけ**、鳴ります（端末が圏外でも、あとで届きます）。
- PC が止まっていた間に過ぎた通知は、起動後に**遅れて届きます（24時間前の分まで）**。それより古い分は、鳴りません。
- 通知を有効にした端末が**1台も無い**間は、何も送りません。初めて有効にしたときは、**すでに過ぎた分を一斉に鳴らさない**ようにしてあります。

**5. 通知が来ないとき**
| 確かめること | 対処 |
|---|---|
| 🔔 を開くと「まだ有効ではありません」 | 「通知を有効にする」を押して、許可する |
| 「ブロックされています」 | ブラウザの設定（Android は、設定 → アプリ → Chrome またはこのアプリ → 通知）で、許可に変える |
| 「対応していません」 | iPhone・iPad は、ホーム画面に追加したアプリで開く |
| 「テスト通知」も来ない | スマホの、電池の節約（バッテリー最適化）で、Chrome が止められていないか。おやすみモードになっていないか |
| テストは来るが、メモの通知が来ない | そのメモに、**日付**と**リマインダー**（⏰「通知しない」になっていないか）があるか。完了・中止・ノートになっていないか |
| どれも来ない | サーバーの PC が起動しているか（`http://127.0.0.1:8765` が開けるか）。「19. 困ったとき」も見る |

## 10. 一覧・検索・並べ替え
- **検索**: `/`（編集中以外）で検索欄へ。空白で区切ると、全部を含むメモ（AND）。日本語の一部分でも見つかります。
- **メニュー**: すべて / 今日 / 次の7日間 / 期限切れ / 日付なし / 完了・中止 / ゴミ箱。「完了・中止も一覧に出す」で、完了も混ぜられます。
- **並び順**（一覧の上の「並び: …」）: 更新日 / 作成日 / 日付 / 優先度 / **完了日** / 題名 / **タグ**（最初のタグの名前順。タグ無しは後ろ） / 手動。
  - **完了日**: 完了にした日時で、新しい順に並びます（「完了・中止」の一覧で使うと便利です。ピン留めは先頭のまま。中止は数えません）。
  - 完了したメモは、一覧に「✓完了 26/10/13」と出ます（マウスを乗せる / メニューで、時刻まで）。完了日は、あとから本文を直しても変わりません（更新日は変わります）。TickTick から取り込んだ完了日も入っています。
  - 手動: メモを**ドラッグ**して好きな位置へ（行の上半分 = その上、下半分 = その下）。スマホは、メモのメニュー →「並べ替え」（先頭へ・1つ上へ・1つ下へ・末尾へ）。順番は全端末で共通。
- **日付の表示**は `26/10/11` の形（マウスを乗せる / メニューで、作成・更新の日時の詳細）。
- **複数選択・まとめて操作**:
  - **選択モード（スマホ向け。PC でも使えます）**: 一覧の上の「☑」を押す（または、メモを長押し →「複数選択を始める」）と、選択モードになります。メモを**タップ**すると、選んだ印（✓）が付きます（もう一度タップで外す）。上のバーに「3件 選択中」が出て、「すべて」で一覧のメモを全部選べます。「まとめて操作 ▾」で、下の一覧のメニューが開きます。終わったら「終了」（または ☑ をもう一度）。選択モードの間は、タップしてもメモは開きません。
  - PC の場合: 一覧のメモを `Ctrl`+クリック（Mac は `Cmd`+クリック）で1件ずつ追加・解除、`Shift`+クリックで範囲を選びます。選んだ行は、色が変わり、右に ✓ が付きます。一覧の上に「3件 選択中」と出ます（数えるのは、✓ の付いた行だけです）。選んでいる間は、いま開いている行の強調は消えます。最初の `Ctrl`+クリックでは、いま開いているメモも、選びに含まれます。ふつうのクリック（メモを開く）をすると、選択はやめます。`Esc` でも解除できます。
  - **まとめてドラッグ**: 選んだ行のどれかを掴んで落とすと、選んだ全部が同じ操作を受けます（左のリスト・タグ・「今日」などの項目・カレンダーの日・画面下の落とし先）。カーソルには「📄 3件」と出ます。選んでいないメモを掴んだときは、そのメモだけが動きます。
  - **まとめてのメニュー**: 選んだ行を右クリック、または「まとめて操作 ▾」: 完了にする・戻す / リスト / タグを付ける / 日付 / 優先度 / 種類 / ピン留め / ゴミ箱へ。`x` キーで、まとめて完了にもできます。
  - **元に戻す**: まとめて操作をすると、画面の下に「3件: … [元に戻す]」が出ます（25秒）。`Ctrl+Z`（Mac は `Cmd+Z`）でも戻せます。戻せるのは、リスト・タグ・日付（予定・通知・繰り返しも）・優先度・種類・ピン留め・完了・ゴミ箱です。ゴミ箱から戻すのは、オンラインのときだけです。
  - ゴミ箱へのまとめての移動は、確認が出ます。まとめての操作では、締切・予定の**自動振り分けは働きません**（仕分けのつもりで選んでいるため）。手動の並べ替えは、複数件では使えません（1件ずつ）。
- **ピン留め**（`p`）: 一覧の先頭に固定。**完了**（`x`、または左の○）。**優先度**（右クリック →「優先度」: 高・中・低。○の枠が赤・橙・青に）。

## 11. カレンダー
### 📆 カレンダー（左のペインに出る小さなカレンダー）
- 日を選ぶと、その日のメモが一覧に出ます。「日付なし」タブで、まだ日付が無いメモを出し、日へドラッグできます。
- 表示する日付の種類: 設定した日付＋本文の日付 / 日付だけ / 作成日 / 更新日 / **完了日**。
  - 「完了日」にすると、**いつ何を完了したか**が、カレンダーに出ます（完了にした日のマスに、完了したメモが並びます。日を選ぶと、その日に完了したメモの一覧）。日付の種類を「完了日」にしている間は、「完了・中止も一覧に出す」の設定に関わらず、完了したメモが対象です。
- `[` `]` で前の月・次の月。`c` で開く。

### 🗓 月カレンダー（大）
- 窓いっぱいの月表示（月曜始まり）。上のボタンで、**月 → 週 → 日**（押すたびに切り替わります。月の日付の数字や、週の日付を押すと、その日の「日」表示へ）、前へ・今日・次へ（`[` `]` も）、日付の種類の選択（「完了日」にすると、帯の先頭に、完了した時刻が出ます）。
- メモは、日付のマスに**帯**で並びます。時刻つきは時刻が先頭（`17:00-19:00 題名` のように）。帯の色は、タグの色。完了したものは薄く、取り消し線。
- 1日だけの予定は、題名が長いと**折り返して複数行**（最大3行）で出ます。同じ日にたくさんあって入りきらないときは、2行 → 1行と詰めて、それでも入らない分は「+N件」にまとめます。
- 複数日のメモは、**週ごとに1本の長い帯**（週をまたぐときは ◀ ▶）。
- 土曜は青、日曜と**祝日**は赤。祝日名も出ます（日本の祝日・振替休日・国民の休日を、計算で出します）。
- **週表示**: 日表示と同じ時間軸を、7日分、横に並べます（月曜始まり。今日の列は薄く色が付きます）。上の「月 11/9」などの日付を押すと、その日の日表示へ。終日・複数日のメモは、上の「終日」の欄に、日ごとに出ます（複数日は ◀ ▶ の印）。時間の欄へのドラッグ（別の日の列へも）・ダブルクリックは、日表示と同じです。
- **帯の長さを変える**（日・週表示）: 時刻つきの帯の**下の端**をドラッグすると、終わりの時刻が変わります（15分きざみ）。終わりの時刻がつくので、「予定」になります。
- **日表示**: 1日の時間軸（0〜24時）に、時刻つきのメモが、時刻と長さの位置に並びます（終わりの時刻が無いものは1時間の長さ）。時間が重なるものは横に並びます。終日・複数日のメモは、上の「終日」の欄に出ます。今日は、いまの時刻に赤い線が出ます。時間の欄をダブルクリックすると、その時刻つきの新しいメモ。**時間の欄へドラッグして落とすと、その時刻（15分きざみ。落とす位置に点線と時刻が出ます）に動きます**。終わりの時刻つきの予定は、長さを保ったまま動きます。上の「終日」の欄へ落とすと、その日の終日になります（時刻は外れます）。複数日のメモは、日付だけ動きます。前へ・次へ（`[` `]`）は1日ずつ動きます。
- 帯を**押す** → 右にメモが開く（「× 閉じる」で閉じる）。帯を**右クリック**（スマホは長押し）→ メモのメニュー（完了・日付・タグ・ゴミ箱など）。
- 帯を**別の日のマスへドラッグ** → 日付が移る（時刻は保たれる）。
- 空いているマスを**ダブルクリック** → その日が日付の新しいメモ。上の「＋」は、今日が日付の新しいメモ。
- 1マスに入りきらないときは「+N件」。押すと、その日を、小さいカレンダーで開きます。

完了にする / 中止にする / 種類（タスク・ノート） / ピン留め / 優先度 / 手動で並べ替える / 日付 / 予定にする・締切に戻す / 複数日 / 時刻 / リマインダー / リスト / タグ / 編集 / ファイルを添付 / リンクにタイトルを付ける / コピー / 履歴 / ゴミ箱へ

## 13. ゴミ箱・履歴・戻す
- **ゴミ箱へ**: `Alt+Backspace`、またはメニュー。**完全には消えません**（ファイルがゴミ箱フォルダに移るだけ）。
- 左のメニューの「🗑 ゴミ箱」→ 一覧 → 押すと中身が読める →「元に戻す」で、元の場所へ（他の端末にも届く）。オンラインのときだけ使えます。
- 完全に消す機能は、事故を防ぐため、意図的に作っていません。
- **履歴**（`Alt+H`）: そのメモの過去の版が、git の履歴から見られます（`↑↓` で選び、`Enter` で本文に戻す）。各行の下には、**その回に何が変わったか**（日付・時刻・完了・中止・リスト・種類・優先度・ピン留め・繰り返し・リマインダー・本文など）が出ます（例: 「日付: 2026/11/10 → 2026/11/15 15:00」）。本文を戻すときは、本文だけが戻ります（日付などは戻りません）。古い100件より前の記録には、説明が付きません。
- 複数の端末で同じメモを同時に編集して、ぶつかったときは、**あとから保存した側が、別のメモとして残ります**（書いた内容は消えません）。

## 14. PC の Chrome から追加する（拡張機能「tick_clone に追加」）
読んでいるページの内容を、あとで見返すために、**1回のクリックで、新しいノートとして入れます**（TickTick の「Add To TickTick」と同じ使い方）。

- **使い方**（Chrome のページの上で）:
  | 操作 | 入るもの |
  |---|---|
  | **文字を選んで、右クリック →「tick_clone に追加」** | 選んだ文章（これが、メモの題名になります）と、ページのタイトル・URL |
  | ページの何も無いところで、右クリック →「tick_clone に追加」 | ページのタイトルと URL |
  | **リンク**の上で、右クリック →「tick_clone に追加」 | そのリンクの URL |
  | **画像**の上で、右クリック →「tick_clone に追加」 | 画像（添付として保存され、本文に表示されます） |
  | ツールバーの拡張機能のボタンを押す | いま開いているページ |
- **できるノート**: 種類は**ノート**です。「ノートにしたメモを、自動で入れる」リスト（資料など）を設定してあれば、**そのリストへ自動で入ります**。タグ `#共有` が付きます。
  - 文字を選んで送ったとき: 1行目 = 選んだ文章 / 続けて、ページのタイトルと URL（出典）/ 末尾に `#共有`。
  - 選ばずに送ったとき: 1行目 = ページのタイトル / 2行目 = URL / 末尾に `#共有`。
- **追加できたかどうか**は、画面の右下に出る通知（「tick_clone に追加しました」「追加できませんでした」）で分かります。**失敗したときは、メモは作られていません**（あとで自動では送りません）。サーバーの PC が起動していて、つながるか確かめて、もう一度やり直します。
- **入れ方**（1台ごとに1回）:
  1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
  2. 「パッケージ化されていない拡張機能を読み込む」を押し、フォルダを選ぶ。
     - このリポジトリの `extension` フォルダ（別の PC では、そのフォルダをコピーして使います）
  3. 右クリックのメニューに「tick_clone に追加」が出れば完了です（出ないときは、ページを開き直す）。
- **送り先**: 先に、拡張機能の「オプション」に入れたアドレス（例: `https://<PC名>.<tailnet名>.ts.net`）、だめなら `http://localhost:8765`（この PC）の順に試します（オプションに「つながるか試す」もあります）。
- Mac から使うには、Mac にも **Tailscale** を入れて、同じアカウントで入る必要があります（入れていないと、「追加できませんでした」と通知が出ます）。
- 送るのは、右クリックで選んだ内容だけで、送り先は自分の tick_clone だけです。

## 15. スマホの「共有」から送る（Android）
ブラウザやほかのアプリの「共有」ボタンから、**tick_clone を選ぶだけで、新しいノートになります**。

- **使い方**: ブラウザ（Chrome など）やアプリで、共有したいものを開く →「**共有**」ボタン → 共有先の一覧から「**tick_clone**」を選ぶ → tick_clone が開いて、新しいメモができます。
- **前もって必要なこと**（1台ごとに1回）: Chrome のメニュー →「**ホーム画面に追加**」（「アプリをインストール」）で、tick_clone をアプリとして入れておく。ふつうのタブのままでは、共有先の一覧に出ません。
  - 共有先の一覧に出ないときは、**一度アプリを消して、入れ直します**（共有先の登録は、反映に最大1日かかることがあります）。
- **できるメモ**: 種類は**ノート**で、末尾に `#共有` が付きます。「ノートにしたメモを、自動で入れる」リスト（資料など）を設定してあれば、そこへ入ります。
  - Chrome の「共有」でページを送ったとき: 1行目 = ページのタイトル / 2行目 = URL。
  - **文字を選んでから共有**したとき: 1行目 = 選んだ文章 / 続けて、ページのタイトルと URL（出典）。
  - **URL だけ**が届いたときは、数秒後に、ページのタイトルが1行目に足されます（PC の Chrome 拡張と同じ）。
- **画像・PDF**: 「共有」で送ると、メモに添付されます（**オンラインのときだけ**。つながっていないと、画像・PDF は添付できず、文字の部分だけのメモになります）。
- つながっていなくても、共有そのものは受け取れます。メモは端末に先に保存され、つながったときに、自動で同期されます。
- **iPhone・iPad では、共有先の一覧に tick_clone が出ません**（Safari が、この方式に対応していないため）。代わりに、Safari の「共有」から URL をコピーして、tick_clone の新しいメモに**貼ります**（URL を貼ると、数秒後に、ページのタイトルつきのリンクになります）。
- 共有されたメモは、「ノートにしたメモを、自動で入れる」リスト（資料など）があれば、**仕分けなくても、そこへ入ります**。別のリストへ動かしたいときは、メモのメニュー →「リスト」、または「21. 棚卸し」です（棚卸しでは、資料のリストは、初めは見る対象から外れています。見たいときは、チェックを入れます）。

## 17. バックアップ・保存場所（運用メモ）
- メモ: `data/notes/`（年/月/ID.md）。ゴミ箱: `data/trash/`。添付: `data/attachments/`。場所は、環境変数 `TICK_DATA` で変えられます。
- `data` は、それ自体が git のリポジトリで、変更のたびに自動で記録されます（約5秒後）。
- **バックアップ**: `python tools/backup.py --dest <保存先フォルダ>`（環境変数 `TICK_BACKUP_DIR` でも指定できます）。メモ＋git の zip を14世代、添付は差分で保存します。毎日動かすには、タスクスケジューラ（Windows）や cron に登録します（README を参照）。
- 索引（`data\index.db`）は、消えても作り直せます。通知の鍵（`data\push\`）は、バックアップに入れていません。
- サーバーの起動: `start.bat`（Windows）/ `start.sh`（Mac・Linux）。PC の起動時に自動で立ち上げる設定は、README を参照（ポートは 8765）。
- **注意**: 8765 を、ほかのアプリが先に使うと、tick_clone が立ち上がれません。

## 18. できないこと・注意
- **既定では、ログイン機能はありません。** 自分の端末だけが、開ける状態で使ってください（`127.0.0.1` のままにするか、Tailscale のような自分の端末だけの回線を使う）。**インターネットへの公開（Tailscale Funnel、ポート開放など）は、絶対にしないでください。** メモが、誰にでも読めて、書き換えられてしまいます。
- **念のための鍵（任意）**: 環境変数 `TICK_TOKEN` を決めて起動すると、トークンを知っている人だけが使えます。ブラウザは `/login` でトークンを入れて入ります（1年間、覚えます）。Chrome 拡張は、オプションの「アクセストークン」に入れます（この端末の中だけに保存）。設定しなければ、認証なしのままです。トークンは1つだけで、通信を暗号化しないので、HTTPS 越し（`tailscale serve`）で使ってください。
- 完全削除（ゴミ箱を空にする）はありません。
- メモ同士のリンク（`[[…]]`）は、まだありません。
- 日付の読み取りは、完全ではありません。メール・ログのような文章は、読み違えることがあります（提案として出すだけです）。
- スマホ実機での確認が、まだ十分でない機能: 月カレンダー（大）の複数日の帯、予定・複数日まわり。

## 19. 困ったとき
| 症状 | 対処 |
|---|---|
| 画面が古い・新機能が出ない | ブラウザを更新（アプリは自動で新しい版に切り替わります）。それでも変なら、サイトのデータ（Service Worker・キャッシュ）を消す |
| 開けない・つながらない | PC が起動しているか確認。サーバーが止まっているときは、`server.log` を見る。ポートの取り合いのときがある |
| スマホ・Mac・別のPCで、ずっと「同期中」「オフライン・送信待ち」のまま | メモは消えていません（端末に残っていて、つながると送られます）。多くは、**サーバーのPCの Tailscale が止まっている**ときです（サーバーは動いていても、外からは届きません）。サーバーのPCで PowerShell を開き、次で確認します。<br>・`tailscale status` … 端末の一覧が出れば正常。「Tailscale is starting」「NoState」と出たら、起動待ちか、止まっています（数分待つ。直らなければ、タスクトレイの Tailscale を一度終了して開き直すか、PC を再起動）<br>・`tailscale serve status` … `https://<PC名>.<tailnet名>.ts.net` から `http://127.0.0.1:8765` へ、と出ていれば正常。「No serve config」なら、`tailscale serve --bg 8765` で出し直す<br>・PC のブラウザで `http://127.0.0.1:8765` が開けば、サーバー自体は動いています<br>復旧したら、スマホはアプリを開き直す（PC のブラウザは再読み込み）と、送られます |
| スマホで通知が来ない | 🔔 で有効にしたか、Chrome の通知がオンか、電池の節約で Chrome が止められていないか |
| 変更が他の端末に出ない | 画面右上の接続表示（オンライン/オフライン）を見る。オフラインなら、つながったときに自動で送られる |
| 間違えて消した・変えた | ゴミ箱から戻す / 履歴（`Alt+H`）から戻す / git の履歴（data フォルダ） |

## 20. 考え方（3つの軸と、作らないもの）
このアプリは、**頭の中を「把握」するための道具**です。何でも放り込んでおいて、あとから取り出してもらう道具では、ありません。だから、置き場所を **3つの軸** に決めて、それ以上は増やしません。

| 軸 | 答える問い | 置き場 |
|---|---|---|
| **状態** | いま、どういう扱いか | **リスト**（1メモに1つ） |
| **テーマ** | どの気がかりの話か | **タグ**（いくつでも） |
| **形** | 単発か、続くか、塊か | **書き方**（「一段落して次へ」・☐） |

- **状態 ＝ リスト**。受信箱 / 未分解 / 具体的な次にとるべき行動 / Oneday（する） / Someday（たぶんする） / やらない / 依頼・他人任せ / 資料、のように、**ほぼ固定**にします。呼び名は変えてよいのですが、箱を足したり減らしたりはしません。自動の振り分け（締切・予定・ノート・フィルターのルール）は、この軸にだけ付いています。
- **テーマ ＝ タグ**。平らに使います。作るかどうかは、**そのタグだけを開いて眺めることが、本当にあるか**で決めます。無ければ、作りません（`#ケイコ_金_住宅` のような細かい枝は、**検索で足ります**）。目安は、自分が覚えていられる数（10〜15 くらい）。覚えていられないタグは、使われずに、ただ増えます。
- **形 ＝ 書き方**。
  - **単発** → ふつうのタスク。
  - **1つ終えて、はじめて次が決まるもの** → 1つのメモのまま「**一段落して次へ**」で育てます（経緯が、振り返りに残ります）。
  - **はじめから全部わかっている塊** → 1つのメモの中の **☐** で並べます。ただし「全部わかっている」は、たいてい錯覚です。1歩目が終わると、3歩目の中身が変わります。**迷ったら「一段落して次へ」**のほうが、うまくいきます。

### 作らないもの（決めごと）
- **タスクの親子（サブタスク）は、作りません。** 親が名前だけのメモになり、子が増えて、メモの総数だけが膨らむからです。塊は、1つのメモの中の ☐ か、「一段落して次へ」で表します。
- **リストの階層は、フォルダ/リストの2段まで。** 深い入れ子は、中身より、構造の手入れに時間を取られます。
- **タグの細かい枝分かれは、作りません**（上の決まり）。
- **ハビット（習慣）・ポモドーロ・優先度の専用マトリクス・カンバンは、作りません。** 保存した絞り込み（フィルター）で足ります。
- **AI には、仕分けを任せません。** 自動で動くのは、**決まり**（締切ならこのリスト、ノートならこのリスト）だけです。本文の日付の 💡 も、**提案するだけ**で、押すまでは何も変わりません。勝手に片づいてしまうと、「把握」できなくなるからです。

機能を足したくなったら、まず「**何を引けるか**」を考えます。

### 仕事の種類ごとの、置き場（まとめ）
| 種類 | 置き場 | やり方 |
|---|---|---|
| **単発**（1回で終わる） | 状態＝リスト | 日付つきならタスク。受信箱で受けて、決まりで仕分ける |
| **1つ終えて、はじめて次が決まる** | 形＝書き方 | 1つのメモを「一段落して次へ」で育てる（経緯は振り返りに残る） |
| **はじめから複数わかっている塊** | 形＝書き方 | たいていは、上の「1つ終えて次が決まる」に畳む。本当に並行して全部必要なものだけ、1つのメモの中の ☐ |
| **責任範囲**（定期的に見にいく） | テーマ＝タグ | `#ケイコ` のような、平らなタグ。単独で開いて眺めるものだけ作る |
| **ただの分類**（見にいかない） | なし | 検索（日本語の部分一致） |
| **繰り返し** | 形＝書き方 | 繰り返し。回の記録は、振り返りに自動で残る |
| **待ち（他人ボール）** | 状態＝リスト | 「依頼・他人任せ」のリスト |
| **まだ始められない** | 状態＝リスト | 時間で待つなら Oneday（締切の7日前に、「具体的な次」へ自動で移る）／出来事・人を待つなら「依頼・他人任せ」 |

古くなったものを正しい場所へ戻す作業は、「**21. 棚卸し**」です。

## 21. 棚卸し（週1回くらいの見直し）
- メモは、書いたときに自動で仕分けされます。ただ、**書いたあとに古くなったもの**（受信箱に溜まったまま、「次の行動」のはずがもう次ではなくなった、など）は、誰も動かしません。それを、1件ずつ出して、1キーで正しい場所へ動かす画面です。
- **開く**: 左のメニューの「🧹 棚卸し」（右に「前回 ◯日前」が出ます）。コマンドパレット（`Ctrl+K`）の「棚卸しを始める」でも開けます。
- **見るリストを選ぶ**: リストごとに、見るものの件数が出ます（チェックで選びます。選びは、この端末が覚えます）。「各リスト、古い順に 10件まで」のように、**1回に見る数を決められます**（全部をやり切る必要は、ありません。5分で切り上げてかまいません）。資料（ノートの置き場）は、初めは外れています。
- **1件ずつ**: 更新が古いメモから、1件ずつ大きく出ます（題名・作成と更新の日・日付・タグ・本文）。下に、動かし先が並びます。
  | キー | 動き |
  |---|---|
  | `1`〜`9` | リストの並び順（左のリスト欄と同じ）の1〜9番目へ入れる。画面のボタンにも番号が出ます |
  | `0` | 受信箱（リストなし）へ戻す |
  | `d` | 完了にする（繰り返しは、その回を完了） |
  | `x` | やらない（中止）にする。実績には数えません |
  | `k` | **このまま置く**。30日間は、棚卸しに出しません |
  | `s` / `→` / `Space` | 今回は何もせず、次へ（次の棚卸しで、また出ます） |
  | `u` / `←` / `Ctrl+Z` | 1つ前の操作を、元に戻す（何回でも） |
  | `Esc` | 終わる |
  - ボタンを押しても、同じです（スマホ・iPad は、ボタンで）。いまあるリストのボタンを押すと、「このまま置く」になります。
  - **「ノートにして資料へ」も、「資料」のリストのキーひとつ**です（そのリストに「入れたらノートにする」が設定されていれば、ノートになります）。
  - ノートは、完了・中止にできません（リストへ動かすか、「このまま置く」）。
- **おしまい**: 動かした数と、リストごとの件数の変化（「Inbox 231件 → 221件」など）が出ます。「もう少し見る」で、続きをやれます。
- 棚卸しの間、裏の一覧は動きません。閉じたときに、まとめて反映されます（他の端末にも、そのとき伝わります）。
- **作らないもの**: 連続日数や点数などの記録、AI による「このリストでは？」という推測、通知での催促。何を、どこへ入れるかは、あなたが決めます。
